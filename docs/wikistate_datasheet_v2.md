# WikiState v2 Datasheet(2026-08-28,Datasheets-for-Datasets 体例)

## 1. 动机与用途

评测长程对话记忆系统的**查询条件化状态有效性**(query-conditioned validity):
同一条记忆在不同查询下分别是过期证据/正确答案/必需证据。适用:记忆系统、
长上下文读者、检索管线的状态类问题评测。不适用:开放域闲聊质量、多模态。

## 2. 构成与规模

- **v2 主考场**:144 条状态链(Wikidata 真实人物属性变更史,P39 职位/P108
  雇主/P54 球队/P551 居住地,P580/P582 起止限定)× 4 题型(change_count /
  count_before / longest_tenure / first_vs_last)= **576 题**(v2.5 起 **560 题**:
  移除 16 道头两名任期相对差 ≤1% 的 longest_tenure 近平局题,见 §3);
- 每链 ≥3 态,渲染为带日期第一人称会话 33-38 场/店 + STALE 式干扰会话;
  店均 51,694 字符(≈1.4 万 tok);语料总量 7.4M 字符 ≈ 2.1M tok;
- 链行 542 行:锚点句逐字核验 542/542、日期合法、非降序(机器全检,2026-08-28);
- **v1 头条场**:105 链/418 题(历史口径,与 v2 绝对分不可比);
- **S8 组合场**:6 组合类型,SEEN(dev,≤3 轮迭代)/UNSEEN(一次性测,
  测前禁触)划分写死于生成器头注;
- **陷阱与弃答子集**:premise_check 假前提陷阱型;STALE 系 400 探针
  (记忆失效觉察);inj30 注错臂(链注错 30% 的对抗店)。

## 3. 金标来源与质控

- 题与金答案**纯代码从链导出,零人工标注裁量**;歧义构型一律跳过;
- 防泄漏三闸:参数可答实体排除、长尾实体优先、化名变体;
- **闭卷污染基线**(2026-08-28 增):零上下文双读者(haiku/gpt-5-mini)
  实测参数可答上限,数字见 results/wikistate_leaderboard_20260828.md;
- 判官:全臂统一 ClaudeJudge(与 LongMemEval 分型协议对齐);
  **机械效度 97.2%**(2,555 可提取计数行,scripts/mech_consistency_check.py v2 规则可复现,逐行产物入档;分歧集中于
  闲聊式直读臂的正则误抓);判官-判官交叉审计 102/102 零偏袒;
- **人工核验(进行中)**:144 链全覆盖,author 全检 + 两独立评审各半区
  + 20 题重叠(不含作者的 Cohen's κ)+ 5 道注错检查题;裁决规则预注册
  (study_logs/labelstudio_HOWTO.md);产出并入 v2.1。
- **任期约定(2026-09-03 明写)**:链只记录记忆日志中**宣告的开始状态**,不建模
  任期结束;一行状态一直"当前"到下一次宣告,末段截至题面 Today。理由:S5 对话
  只含开始宣告,真实离职日期在记忆库内不可推导,用世界真值判店内可答性是错的标准
  (results/longest_tenure_gold_prereg.md,2026-08-20)。后果已量化(results/
  b35_tenure_gaps_v25.json):367 个有 Wikidata P582 的相邻转移中 105 个(80 链)
  结束日早于下一行开始日超过 1 年;若按真实任期重算,136 道 longest_tenure 题中
  53 道 gold 会变。示例 wikiP39042-Q994984:第 47 届议会行(1974-10-10,
  P582=1979-04-07)按约定延续到 1992-04-09 的下一次宣告。该约定对各臂信息对等
  (33-A 单店:约定敏感 57 题 smoc 87.7 / direct 38.6,非敏感 87 题 90.8 / 28.7),
  不偏袒任何一臂;评审说明与题面 CONVENTION 行同步明写,评审不得因"缺结束行"报错。
- **同机构多实体**:P108 取 Wikidata 实体原值,同一机构家族的不同实体(如 Weill
  Cornell Medical Center / Weill Cornell Medicine,wikiP108026)按雇主变化处理
  (作者裁定 2026-09-03)。
- **近平局题移除(v2.5)**:longest_tenure 的唯一性只在天粒度成立;按题面 Today
  与 tenure_gold 同口径,144 题中 16 题头两名相对差 ≤1%,自 v2.5 起移除
  (勘误:首版 v2.5 用 400 天启发式误删 2 题、漏删 10 题,2026-09-03 更正)。

- **店版本纪律**:一切卡店衍生数字挂店版本与建店日期(v42=2026-08-23,

## 6. 已知局限(与论文 limitations 同源)

主结论域为合成语料;逐字植值+干净日期为工作前提(孪生替换半边零效应);
自然语料链抽取未过闸(35% 改判率);条件绑定型偏好为已量化盲区
(opt_batch20_verdict);域覆盖 4 个 Wikidata 属性(新域 P26/P69/P1303
已探明待扩)。
- **语料存储瑕疵(2026-09-04 记)**:助手轮以 400 字截断的 Python 字典字符串存储(2,160 条中 2,156 条),全上下文读者看到的是半句;所有臂同等受影响,配对比较不受影响,但作为原始语料的可读性缺陷记入,v2.6 规范化。填充会话含 1,014 处年代错乱(不碰金标)。
- **槽位分布不均**:residence 仅 11 链(employer 51 / position 44 / team 38);链长以 3 态为主(86/144)。
- **抽取非确定性与读者抖动(批 41/46c)**:同一抽取器两遍抽卡的卡片重叠仅 2–33%;140 题子集上读者单次运行抖动 3–4 pp,涉及"追平"类主张须多次运行取均值。
- **版式份额(批 44)**:同版式关机制的渲染对照 85.0、原句同版式 85.4、账目 89.3;账目对裸全文的增益约 88% 归于"同槽位带日期行 + 轨迹协议",卡片抽取残差 +4.3(小库、haiku)。
