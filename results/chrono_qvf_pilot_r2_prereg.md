# 预注册:ChronoScope × QVF 试点第 2 轮——知识筛选子集(先于跑数提交)

日期:2026-08-21。承接:`results/chrono_qvf_pilot_verdict_r1.md`(C4 地板效应,
C1 不可测)。修法镜像我方对论文的 F1 批判处方:**限定轮 0 答对子集**。

## 设计(相对第 1 轮只变一个东西:抽样加知识筛)

1. **探针池**:5 个作用域链族 × 各 600 链(is_drift_candidate=true,族内 chain_id
   排序等距,确定性)= 3,000 链。
2. **知识探针**:每链只问轮 0 问题(含显式年份,独立作答,同读者 haiku-4-5,
   temp 0,同 relaxed 判分)。答对 → 入筛选池。探针即 A0 轮 0 的复用,不另设口径。
3. **第 2 轮样本**:筛选池内族内 chain_id 排序等距抽取,每族至多 12 链,合计至多
   60 链(若某族产出 <12,如实取全并入档,不跨族补)。
4. **臂与判据**:与第 1 轮预注册完全相同(A0/A1/A2/A3;C1 病灶复现 → C2 Drift
   减半主判据 → C3 Acc 次判据)。C4 在本轮按构造应满足(样本全部轮 0 答对);
   若筛选池 <20 链,判"knowledge floor 过低,haiku 上不可测",第 3 轮换强读者
   另行预注册。

## 读者不换的理由(单变量纪律)

第 1 轮失败归因于抽样(长尾实体)× 读者知识的交互;先修抽样、保读者,
才能把"筛选修法是否足够"单独判定。换读者与换抽样同时动,归因就废了。

## 可证伪预测

- 探针通过率:1–8%(第 1 轮 A0 轮 0 为 1.7%,筛选池预计 30–240 链);
- 筛后 A1 追问轮:Drift > 0(知识在场,漂移可测)且 Acc 显著低于轮 0——C1 复现;
- A2:Drift ≤ A1 一半(主判据方向);若 A1 Drift 本身 <5%,判"haiku 在此设定下
  不漂",如实入档——这同样是有价值的结果(与论文闭源模型 drift 0.16–0.35 对照)。

## 成本

探针 3,000 次(~60 in/15 out tok)≈ $0.35;四臂 ≤60 链 ≈ $0.35;合计 **≈$0.7**。
无论方向如实入档。
