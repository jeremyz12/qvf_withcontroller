# 预注册:装配层链成员资格过滤器(LLM 语义角色判断 + 确定性授权)

## 设计来源(三篇方法节精读的融合,见 solution-methods-read 工作流)
- **问句**(自家诊断):判"这张卡是不是槽位 X 的一次状态宣告"——语义角色,
  **不是** ConsistencyGate 的"是否被上下文支持"(污染物恰被支持,该问句零区分度)
- **K=1**:ConsistencyGate 消融 K=1≈K=5,单次调用拿走几乎全部收益
- **never-infer 负约束**(Schema-Grounded):无显式宣告证据 → not_member,
  禁止凭主题邻近推断;输出强制带 evidence 引文
- **确定性授权**(StateAuditor VTA):模型只提议,代码授权——引文必须钉回
  该卡自己的逐字锚点(子串),锚点必须在库原文中;钉不上 → fail-closed 判非成员
- **预警**(ConsistencyGate 隐式事实召回 0.58):跨轮合并的隐式宣告允许计为成员;
  评测报告过滤删除率,防错杀

## 实现
`scripts/chain_membership_filter.py`:对每库目标槽位的选池(与执行器同一
`_select_pool`),一次 haiku-4-5 调用(temperature 0)逐卡判成员;授权通过的
成员卡保留,其余**从库副本中移除**(本批基准每库单槽位,移除无旁伤——如实声明
这是基准特定简化);产出过滤后卡片库目录 `*_mf`。

# 追加预注册:集合语义装配器(QVF_SET_SEMANTICS,2026-08-20)

写于跑数前。**动机被两次独立指认**:实验 C 判决(集合批卡片臂 −11.70pp,
编译臂把累积当替换算)与成员过滤器 C1 分裂判决(集合批过滤无效,病在装配不在成员)。
卡片自带 `slot_cardinality` 字段(set 占 36–39%)但下游从未分叉 —— 本旗标补上分叉。

## 实现
`QVF_SET_SEMANTICS=1`(默认 0,关时逐字节等价):`execute_plan` 装配链后,
若链上多数记录 `slot_cardinality=='set'`,则 current / point_in_time /
count_changes 三个算子切换集合语义:
- current → 列出**全部**现值(带各自加入日期),声明"累积属性,早先项仍然成立"
- point_in_time → 截至该日**已加入的全部值**
- count_changes → **不同值的个数**(集合基数,非变更次数)
trajectory 原语义即累积顺序,不改;longest/count_before/first_last 保持替换语义。
