## 0. 判决(先判决,后数字)

- **H1(WikiState 560 题 ≥ 92.5)被证实。** v55f 两轮 94.64 / 93.57,均值 94.1,552/560 题两轮一致;对 v48f +4.8 / +3.4(McNemar p = 2e-4 / 0.011,144 链簇自助 95% CI [+1.8, +8.0] / [+0.4, +6.7]);对 v45 +5.4(p = 1e-4);对全文加协议 +8.0(p = 4e-7,CI [+4.8, +11.3]);对特调版 v52f −0.7(p = 0.61)。**不带任何特调的配置在全量上显著高于旧店和最强的单次调用 harness,与特调版不可分。**
- **H2(第三方考场不低于旧建卡 3 个点)按点估计未过,但差异不显著,而且追加对照证明差异不是本周改动造成的。** STALE 40 店 55.0,对旧建卡 61.7 −6.7(p = 0.24),对直读 +8.3;MemOps 40 店 48.3,对旧 52.5 −4.2(p = 0.47),等于直读。**对照:同 20 个 STALE 店用新建卡器、默认设置、不含本周任何改动重建,60.0,对旧建卡同样 −6.7(p = 0.45),对主线配置 +1.7(p = 1.0);卡片数 169 对旧 166。** 所以主线配置与"原配置重建一次"不可分,STALE 上的 −7 是抽取运行间差异(60 题上约 ±6 个点),不是闭集规则、值规范化或过滤的代价;批 49、50 对精简契约的归因也要据此降级为"未分离出建卡差异"。
- **H3(Sonnet 140 题 ≥ 92)按点估计未过,不显著。** v55f@Sonnet 91.4,对 v47skf 95.0 −3.6(p = 0.23),对 v52f 92.9 −1.4,对读时抽表 harness 92.9 −1.4,对整份记忆朴素读 97.1 −5.7(p = 0.08)。强读者小库那一格仍是全上下文赢。
- **H4(成本 ≤ $45)被证实:** 建店 $19.1 + 蕴含 $4.4 + 读者与判官约 $9 + 对照 $6 ≈ $38。

**结论句**:主线配置是可以写进方法节的通用配置。WikiState 上它对旧店 +4 到 +5、对全文加协议 +8,显著;两个第三方考场上与原版 QVF 的差在抽取噪声内,没有可归因于本周改动的损失;它在 STALE、MemOps 上仍高于或等于直读,低于或等于原版。写侧改动的收益集中在 WikiState 这类槽位化的状态链上;在日常状态考场上没有收益也没有代价。
