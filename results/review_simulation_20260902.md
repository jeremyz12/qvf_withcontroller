# 人工核验模拟(机器复核 149 题)与三方对照 —— 辅助材料

日期 2026-09-02。用户指令:模拟 author / senior1 跑一遍,看有多少题有问题,
并记录步骤与结果。**结论先行:模拟完成了,但它自身的效度检验否定了它作为
人工核验替代品的资格。** 详下。

## 一、步骤(可复现)

1. **取界面版链**:从 rate.db 的 items 表解析 149 题实际显示的链行(含 5 道
   对照题的植入错误)——与人类看到的完全一致,而非本地干净链;
2. **取原文**:v2.0 语料(第一轮评审所用版本),用户与助手轮全给;
3. **同一判据**:提示词逐字复用界面上的问题("该状态链是否正确且完整地
   代表了人设在该槽位的历史?"),五类错误全查(漏检/值错/日期错/多余行/
   顺序取代错),输出 correct|errors|unsure + 具体注释 + 逐字引文;
4. **机核**:凡声称 MISSING/EXTRA 必须给出原文中逐字存在的引文,不通过则
   标记为低置信;
5. **两把尺子打分**:①5 道对照题(已知答案=errors);②senior2 的 84 题
   人类判定。
脚本 scripts/machine_review.py,产物 results/machine_review_149.jsonl。

## 二、结果(按三人题集切分)

| 题集 | 题数 | 机器判 errors | 其中引文机核通过(高置信) |
|---|---|---|---|
| author | 149 | **98(66%)** | 75(50%) |
| senior1 | 85 | **59(69%)** | 47(55%) |
| senior2 | 84 | **52(62%)** | 37(44%) |

判定分布(149):errors 98 / unsure 24 / correct 27;错误类别几乎全是
MISSING(98),WRONG_DATE 4、WRONG_VALUE 1。声称引文的 96 条中 75 条通过
机核,**21 条引文在原文中不存在(幻觉)**。

## 三、效度检验:两把尺子给出相反的结论

**尺子① 对照题:5/5 全中**(senior2 为 2/3)。植入的 value_swap /
date_shift / delete_row / fabricate_anchor / add_row 全部被识别。

**尺子② 人类判定:一致率仅 39.3%,Cohen's κ = −0.013(等同随机)**。
机器报错率 61.9% vs senior2 报错率 8.3%;人判 errors 的 7 题机器召回 4 条
(57%),但机器在 senior2 判 correct 的 47 题上报了错。

**尺子③(追加)与 Fable 严判污染集的重合**:机器高置信 errors 75 题中,
落在 Fable 复审确认的污染链上的占 **43%**——而全部 149 题的基线就是
**41%**。**零富集**:机器的标记与严格裁定的污染集基本不相关。

## 四、判读:单遍 LLM 复核不可替代人工

- 机器能抓**露骨的植入错误**(对照题 5/5),因为那类错误在链表层面即可见;
- 但在**需要判断"这句话算不算一次状态"**的地方,它**无差别报错**
  (66% 报错率),标记与严判集零富集、与人类判定 κ≈0;
- 对照实验说明问题不在"机器不行",而在**流程**:同一底座模型在
  「扫描 → 引文机核 → 分档 → Fable 逐条读上下文复审」四段流水线下,
  产出的污染集与人类独立发现**富集 7.2×(p=0.053)**;单遍直接判则退化到
  随机。**多段对抗式裁决是有效性的来源,不是模型档位。**

## 五、对项目的三条结论

1. **人工核验不可省**:第二轮的 85 题三人重叠集(κ 的唯一来源)价值不因
   本次模拟而降低,反而更高——机器给不出可信的替代数;
2. **本模拟的可用产物**:①对照题 5/5 证明界面与题目渲染无误;②21 条幻觉
   引文提示"逐字引文机核"这道闸必须常设;③高置信 75 题可作为人工复核的
   **优先队列**(不是判定),但须知其富集为零,优先级价值有限;
3. **入 datasheet**:本节作为"我们尝试用 LLM 替代人工核验并失败"的记录,
   与 27-30 批的判负记录同类——负结果照记。
