# 预注册:补测 wt 臂在"从没跑过"的 STALE-full 题上的表现

写于开跑前,不得挪动。

## 为什么必须测
`QVF_ROUTER_LEXICAL` 接线后暴露:部署表(全量拟合)把 **976/4633 = 21.07%** 的题
派给 `wt`,而这些题**从没跑过 wt**(其 350 个 uid 无卡片库)。两种口径给出相反结论:

| 对"没跑过的臂"的处理 | acc | tok |
|---|---|---|
| armdom `resolve()`:当臂不可用,回落便宜臂 | 72.82% | 1,841 |
| 生产 harness:当答错 | 70.29% | 1,875 |
| 出厂 v4.2 | 72.24% | 3,439 |

**两者都不是真相;真相在这批题上未测量。** 本实验就是去测它。

注:2 折 CV 下该比例只有 5.2%,部署表把它放大到 21.07%——
**CV 低估了部署时的洞,这本身是一条须入档的方法学结论。**

## 抽样(先行,不全测)
全测 976 题需建 350 个库,≈**$27.93**,超 $5 上限。
故抽 **50 个 uid / 143 题**,种子 **20260818** 写死,清单已落盘
`results/armdom_wt_sample.json`。预估 **$4.02**(建卡 $3.00 + 读者 $0.58 + 判官 $0.44)。

## 配方(反查确认,非按名猜)
已有 wt 结果的 50 个 STALE-full uid,其卡片在 `results/wt_cards` 与
`results/wt_cards_stalefix`,记录字段**均无 `owner` / `slot_class`**
→ 该线是 `QVF_CARD_KEYS=0`(基底提示词),与 v42/p6 那条线相反。本次照此建卡。

`QVF_CARD_TEMP0` 取**当前已采纳的默认值 1**(08-17 T3 正式采纳)。
**须同页写明的混淆**:归档那 150 行的卡片建于采纳之前(未固定温度),
故 41.3% 这个锚点与本次不完全同条件。

## 判据(先写死)
以抽样 143 题上 wt 的准确率 `p` 为准:

| p | 判决 |
|---|---|
| **≥ 35%** | wt 在这批题上**可用**;乐观口径接近真相,armdom 的 +0.58pp 一侧成立,应按 wt 实测值重算总账 |
| **15% ~ 35%** | wt **弱于**回落臂但远好于 0;两种口径都错,须按实测值重算,结论落在区间中部 |
| **< 15%** | wt 在这批题上**基本失效**;生产口径接近真相,**准确率结论确定为负**,armdom 表须禁止在此类库上选 wt |

同页必报:95% 置信区间、与归档 150 行 41.3% 的对比、实测成本。

## 纪律
- 不触碰 S8 持出集
- 建卡只针对抽样的 50 个 uid,不动其余 300 个
- 超 $5 须停并报批;本批预算 $4.02

# 判决(2026-08-19,跑批后写入)

## 判据②触发,而重算的结论是:零 LLM 路由用 token 换准确率,不是双赢

抽样 150 题(50 uid,种子 20260818):**wt = 51/150 = 34.00%,95%CI [26.4, 41.6]**。

落在预注册的 15–35% 区间 → **判据②:两种口径都错,按实测重算**。
(诚实标注:34.00% 距 35% 的分界只差 1pp,CI 上界 41.6 已越过该线,故①不能被排除。)

对照:
- 归档 150 行有 wt 的 STALE-full 锚点 **41.3%**,本次 **−7.33pp**
  (混淆:锚点建于 `QVF_CARD_TEMP0` 采纳之前,非完全同条件)
- 生产 harness 的假设 0% —— **明确错误**
- 分题型:premise 40.0% / still 34.0% / natural 28.0%

## 重算后的总账(用实测 34.00% 替换假设值)

| 口径 | acc | tok | Δacc | Δtok |
|---|---|---|---|---|
| 出厂 v4.2 | 72.24% | 3,439 | — | — |
| 乐观(未跑过→回落便宜臂) | 73.06% | 1,949 | +0.82 | −43.3% |
| **实测(未跑过→wt 34.00%)** | **70.65%** | **2,160** | **−1.60** | **−37.2%** |
| 悲观(未跑过→算答错) | 65.51% | 2,160 | −6.73 | −37.2% |

**CI 传播后整个区间都是负的**:下界 69.50%(−2.75pp)/ 点估计 70.65%(−1.60pp)/
上界 71.79%(−0.45pp)。

**此前报的 +0.67pp、+0.58pp、+0.82pp 全部撤回。** 它们是删失造成的假象:
回落策略把这些题给了便宜臂,而便宜臂在这批题上恰好优于 wt 的真实表现。

token 节省同步下修:实测 STALE 的 wt 为 **3,342 tok/题**,比 triples 均值 2,873 高 16%,
故节省从 −46% 缩到 **−37.2%**。

## 可以对外说的唯一版本
> 零 LLM 词法路由 + 删除 rt 臂:**token −37.2%,准确率 −1.60pp
> [CI −2.75, −0.45],零在线 LLM 路由调用。**

这是一个**权衡**,不是改进。谁在意 token 谁用它;在意准确率的不该用。

## 一条方法学结论(须入档)
"未跑过的臂"在部署表下的命中率是 **15.1%–21.1%**(区间来自:该计数本身依赖
如何回填观测——回落口径下 976 题,实测口径下约 700 题),而 2 折 CV 下只有 5.2%。
**交叉验证测的是"这个方法值多少分",不测"部署会撞上多少未定义行为"。**
