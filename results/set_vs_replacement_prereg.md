# 预注册:结构化时序机制的适用边界由「替换型 vs 集合型多值属性」决定

写于开跑前,不得挪动。

## 命题

> **QVF 类结构化时序机制的增益,由语料中多值属性是「替换型」还是「集合型」决定。
> 替换型占优时增益为正,集合型占优时为负。**

**机制**:QVF 把每一组 `(属主, 槽位类)` 都当作**替换链**处理
(已知未修缺陷:`slot_cardinality=set` 占 36–39% 却全部按替换链走)。
在集合型属性上,`count_changes` / `longest` / `point_in_time` 算的是**不存在的"变更"**——
`sport_activity = [soccer, swimming, tennis, volleyball]` 被当成"换过 3 次运动",
而真相是同时进行。

## 已观察到的相关(**本预注册之前已看到,故不作为检验,只作动机**)

| 卷 | ≥3 值链 | set 型占比 | wt−提示词 |
|---|---|---|---|
| wiki-P108-ext | 456 | 40% | +34.8pp |
| wiki-P39-ext | 273 | 35% | +32.4pp |
| confirm-228 | 399 | 41% | +17.5pp |
| chain-212 | 368 | 43% | +10.8pp |
| LoCoMo | 61 | 61% | −11.6pp |
| STALE-full | 305 | 73% | −23.3pp |
| LME-TR | 376 | 75% | −17.3pp |
| LME-KU | 216 | 78% | −28.2pp |

**诚实声明**:上表是**先看到再形成假设**的,存在事后归纳风险。
以下三个实验中,只有 **实验 C** 是真正的前瞻性检验。A/B 为辅证,判据同样先写死。

## 实验 A($0)· 跨语料相关

**做什么**:8 卷的 set 占比 vs `wt − 提示词臂`,报 Pearson r 与 Spearman ρ。

**判据**
| r | 判决 |
|---|---|
| ≤ −0.70 | 相关成立(**但因事后归纳,只作辅证,不得单独引用**) |
| −0.70 ~ −0.40 | 弱相关 |
| > −0.40 | 相关不成立,命题的跨语料证据被否定 |

**必须同页写**:n=8、set 占比与语料类型(自建/自然)高度共线、本表为事后观察。

## 实验 B($0)· 卷内分层(控制语料)

**为什么只能在两卷做**:`chain-212`(21 槽位)与 `confirm-228`(22 槽位)是**仅有的**
多槽位卷,其余 13 卷每卷只有 1 个槽位,无法卷内分层。

**做什么**:合并两卷 440 题 / 43 个槽位。对每个槽位,用卡片算它的
`slot_cardinality=set` 记录占比,按中位数分成高/低两组,比较组间 `wt − 提示词臂`。

**判据**
| 高 set 组 − 低 set 组(wt−提示词) | 判决 |
|---|---|
| ≤ −10pp 且 bootstrap CI 不含 0 | **卷内成立**,语料类型被排除,命题获因果性支持 |
| −10 ~ 0pp | 方向一致但不显著 |
| > 0pp | **卷内被否定**,跨语料相关须归因于语料类型而非 set 占比 |

**必须同页写的限制**:这两卷的金链**全部构造为替换型**,所以分层依据是
**抽取器判定的** `slot_cardinality`,而非真值。因此本实验测的是
"当抽取器认为是集合时 QVF 是否更差",**与抽取质量混淆,不是干净的因果检验**。
干净的因果检验是实验 C。

## 实验 C(花钱,预算不限)· 集合型孪生题集 —— **唯一的前瞻性因果检验**

**设计**:用**同一个生成器**(`scripts/gen_stale_chain.py`,同一模型、同样的干扰会话、
同样的会话长度与题型模板)生成两批条目,**只有值之间的语义关系不同**:

| | 替换型(现有) | **集合型(新造)** |
|---|---|---|
| 槽位举例 | phone model / car model / residence city | hobby / sport / collectible / subscription |
| 值的关系 | 后值**取代**前值 | 后值**叠加**,前值仍有效 |
| 生成措辞 | "moving/changing/switching" | "also picked up / added / still doing" |
| 金答案 | 变更次数 = len−1;某日状态 = 区间覆盖值 | **当前持有数 = len**;某日持有集 = 截至该日的全部值 |

**四类匹配问法**(与现有 dim1/2/4/5 一一对应):
| 替换型 | 集合型 |
|---|---|
| 我现在用什么手机 | 我现在有哪些爱好 |
| 我换过几次手机 | 我有几个爱好 |
| 2023-05 时我用什么手机 | 2023-05 时我有哪些爱好 |
| 我的手机变化历程 | 我的爱好是怎么积累的 |

**臂**:直读 / 提示词臂 / wt(卡片臂)/ 编译臂,四臂同题。

**判据(先写死)**
| 结果 | 判决 |
|---|---|
| 替换型 `wt−提示词` **> 0** 且 集合型 **≤ 0**,两者 95%CI 不重叠 | **命题被证实**:语料类型、生成器、读者、判官全部相同,唯一变量是值的语义关系 |
| 两者同号且 CI 重叠 | **命题被否定**:set/replacement 不是决定因素 |
| 集合型 > 替换型 | **命题反向**,须重新解释全部跨语料观察 |

**规模与成本(预算不限,但仍报出)**
- 生成 50 条集合型条目(opus-5,与原生成器同模型)≈ $6
- 建卡 50 库 ≈ $5–16(单价按域实测,不套用 WikiState 的 $0.06/库)
- 四臂 × 200 题 ≈ $5
- **合计 ≈ $16–27**

**防自欺三条**
1. 集合型条目的**干扰会话与替换型同源**(从同一 haystack 池抽),避免"新数据更难"
2. 金答案**纯代码机械导出**,与替换型同一套验证器(逐字锚点、日期递增、值两两不同)
3. **先跑替换型复现**(用现有 chain-212 的产物核对新跑批口径一致),再跑集合型

## 三个实验的证据强度
**C > B > A**。A 是事后观察,B 与抽取质量混淆,**只有 C 是前瞻性的、控制了语料的因果检验**。
论文里 A/B 只能作为"我们先观察到、再设计了 C"的叙述,**不得作为独立证据**。

# 实验 B 判决(2026-08-19)与追加的实验 B′

## 实验 A 判决
Pearson **r = −0.963**,Spearman **ρ = −0.952**(n=8 卷)→ 判据"≤−0.70"触发。
**但按预注册,这只是辅证**:事后归纳,且 set 占比与语料类型(自建/自然)高度共线。

## 实验 B 判决:**卷内被否定**
43/43 槽位、440/440 题:

| | |
|---|---|
| 低 set 组(23 槽位/228 题) | +12.72pp |
| 高 set 组(20 槽位/212 题) | +16.04pp |
| **高 − 低** | **+3.32pp**,bootstrap 95%CI **[−8.80, +15.56]**(含 0) |
| 槽位级相关 | **r = −0.055**(n=43) |

**在同一语料内部,set 占比与 QVF 优势几乎零关系。**
故实验 A 的 −0.963 **不能归因于 set**,须归因于与语料类型共变的其他因素。
**上一轮"set 语义就是失败机制"的说法据此收回。**

**功效限制(同页必报)**:43 槽位中 **23 个 set 占比恰为 0%**,有意义变异仅在 0–67%,
高端只有 2 个槽位。B 否定的是"0–30% 窄区间内的效应",不是"set 完全无关"。

# 实验 B′($0)· 卷内按「日期覆盖率」分层

**动机(来自 B 之后的观察)**:输的四卷另有一个更极端的特征——
"一个日期都没有的链"占 **62–70%**(赢的四卷 39–53%),
而 QVF 的全部算子(`count_changes`/`longest`/`point_in_time`)**都靠日期排序**,
无日期记录进不了链。

**做什么**:与 B 同样的 43 槽位 / 440 题,改按该槽位命中记录的
`stated_date` 非空比例分高/低两组(中位数切分),比较组间 `wt − 提示词臂`。

**判据(先写死;方向与 B 相反 —— 日期越全,QVF 越该赢)**
| 高日期覆盖组 − 低日期覆盖组 | 判决 |
|---|---|
| **≥ +10pp 且 bootstrap CI 不含 0** | **卷内成立**:日期覆盖率是真变量,语料类型被排除 |
| 0 ~ +10pp | 方向一致但不显著 |
| **< 0** | **卷内被否定**,该解释同样作废 |

**同页必报**:槽位级相关 r、两组的日期覆盖率范围(若同 B 一样被压缩,须声明欠功效)。

**对实验 C 的影响**:若 B′ 成立,C 的孪生集**必须控制日期覆盖率**——
否则集合型条目天然少日期,会把两个变量混在一起,C 就白做了。

## 实验 B′ 判决:**方向一致但不显著**
43/43 槽位、440/440 题,日期覆盖率范围 0–100%:

| | |
|---|---|
| 低日期覆盖组(23 槽位/220 题,≤10%) | +11.36pp |
| 高日期覆盖组(20 槽位/220 题) | +17.27pp |
| **高 − 低** | **+5.91pp**,bootstrap 95%CI **[−5.69, +18.41]**(含 0) |
| 槽位级相关 | **r = +0.039**(n=43) |

# 三个候选机制的总判决(2026-08-19)

| 候选机制 | 跨语料 r | 卷内检验 | 判决 |
|---|---|---|---|
| **set 占比** | −0.963 | 高−低 +3.32pp,CI 含 0,r=−0.055 | **否定** |
| **日期覆盖率** | +0.827 | 高−低 +5.91pp,CI 含 0,r=+0.039 | **不显著** |
| **对话轮数** | −0.864 | 15/15 卷 CI 含 0 | **否定** |

**另:全部记录上的 `set%` 与优势相关为 +0.295(正号)**,与"≥3 值链上的 set%"
给出的负相关方向相反 —— 此前那个负相关是**统计口径造成的假象**,
"set 语义是失败机制"的说法**据此彻底作废**。

**结论**:三个跨语料强相关全部进不了卷内。那些相关只能归因于**与语料构造方式共变**
的因素,而这恰是本预注册要排除的混淆。**目前没有找到可在卷内验证的机制。**

**纪律记录**:三次都是先看到跨组相关、就地编机制解释,再去做控制检验。
应当反过来 —— 跨组相关只能提出假设,机制主张必须在 X 有变异的最小单元内部先验过。

# 实验 C 修订(2026-08-19 晚,依 Fable-5 审阅发现 ③)

**问题**:原计划以现有 chain-212/confirm-228 作替换侧,但其 dim2 是预设陷阱题
(gold=末值),而集合侧 dim2 是计数题(gold=len)——问法类型混进唯一自变量。

**修法(采纳审阅建议 a)**:补造**替换型孪生批**(`scripts/gen_replchain_twin.py`),
与 `gen_setchain.py` 逐项对称:

| | 替换型孪生批(新) | 集合型批 |
|---|---|---|
| dim1_current | 现在的值(gold=末值) | 现在的全部(gold=全集) |
| **dim2_count** | **换过几次(gold=len−1)** | **有几个(gold=len)** |
| dim4_point_in_time | 某日的值 | 截至某日的全集 |
| dim5_trajectory | 变化历程 | 累积历程 |

同一 seed(20260819)、同模型(opus-5)、同 `build_haystack`、同状态数分布、
同逐字锚点校验。语言约束对称:集合侧黑名单禁替换词;**替换侧黑名单禁累积短语**
("also picked up" / "on top of that" / "still doing ... and now" / "added another" /
"to the rotation" / "as well as my")。

**固有混淆(如实声明)**:主题与语义天然绑定(phone model 只能替换,hobby 只能累积),
故「主题」无法与「值语义」解耦——这是该操纵的本性,缓解手段即上述全部对称控制。

**判据不变**(见原实验 C 节),但比较基准从 chain-212 改为**本孪生批**,
dim2 恢复参与比较。

**做什么**:`QVF_FULL_CONTEXT=1` 下的 `wsc_direct_arm.py`——跳过检索,

# 判决 · full_context_direct(2026-08-19 晚,$7.63)

| 臂(同 418 题) | tok/题 | 倍率 | acc |
|---|---|---|---|
| 直读 k=10 | 962 | 1.00× | 48.33% |
| 直读 k=24 | 2,097 | 2.18× | 51.67% |
| 直读 k=40 | 3,443 | 3.58× | 54.55% |
| **full-context(整库)** | **14,780** | **15.37×** | **50.48%** |
| usability | 2,438 | 2.54× | 77.27% |
| 编译臂 | 2,069 | 2.15× | 83.73% |

**判据 <60% 触发:全口径下预算解释也不成立,token 判据恢复原强度。**

- full-context 拿到的预算是全口径目标(9,372)的 **158%**,成绩反而**低于 k=40**
  (50.48% vs 54.55%)——预算曲线不但平,**过了峰值还向下**
- full-context vs 直读 k=10:+2.15pp,χ²=0.47 **n.s.** —— 信息全在眼前仍不会答
- 编译臂 − full-context = **+33.25pp**(χ²=111.4,p<0.001),**用它 1/7 的 token**
- 分题型:`longest_tenure` 42.72→**30.10**、`count_before` 51.43→48.57 —— 聚合题
  给全信息反而更差;唯 `first_vs_last` 受益(75.24→94.29,找首尾两条,更多上下文直接有用)

**这在新域复现了项目最初的动机锚点**(STALE 整库入上下文 66.7%、陷阱题塌 49%):
瓶颈不是信息可及性 —— 是不知道**哪些记录构成答案集**。

Fable-5 审阅发现 ② 至此闭环:读取侧口径(A/B)与全口径(full-context)双双成立,
「预算不能解释机制差」可以全口径口吻写进论文。

## 对论文主张的影响(重大)
- **WikiState 聚合题集上的编译臂优势(83.73% vs 直读 48.33%)连另一个合成替换域
  都不能复现** —— WikiState 的逐字植入值 + 干净日期使目标槽位抽取近乎完美,
  是该优势的隐性前提,必须写为限定条件。
- 可跨语料声明的收窄为:**结构化机制在"某日状态"与"变化历程"两类问题上
  稳定为正(三个语料一致),在"当前值"类为负,在集合语义语料上整体为负。**
