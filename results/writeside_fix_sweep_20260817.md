### 总判决:"赢的卷用干净库、输的卷用脏库"这个混杂,修完三卷之后还剩多少?

**方向上的混杂已清零;幅度上的混杂完全没清掉,而是被换成了三个新的、与卡片库无关的解释。**

混杂原本的形状是:QVF 赢的 WikiState 各卷用 `wt_cards_v42`(碰撞 0.0%)/ `v43`(0.5%),而三个"卡片机制失效"的卷全部用碰撞 35–53% 的 `results/wt_cards`。这个相关性现在**被三卷同时破坏**:

1. **没有任何一卷在干净库下,卡片臂仍低于同题直读。** KU 追平(80.77% vs 78.21%)、TR 显著超过(60.15% vs 47.37%)、STALE 合计显著超过(56.67% vs 45.33%),连最保守的 dim3_natural 也只是 −2.00pp(p=1.0)。**"这三卷是卡片机制的适用边界"这条解释,在三卷上全部失去证据基础。**
2. **对应地,"C 类适用边界"里以语料性质(缺少可追踪结构化状态变化)解释负结果的那几条,已由"库脏"这个更简单的原因取代**,且取代是有机制链支撑的、不是靠拟合:三卷 `dropped_n` 同向大降(KU 30.88→10.58,TR 20.07→6.81,STALE 97.81→41.59),且**效应量与碰撞率同向**(碰撞 52.75% 的 STALE 误删量约为 KU 的 3 倍)。TR 上还有内建安慰剂对照:增益严格落在真发生碰撞的 115 个 uid(13–3,p=0.0213),在 16 个"修复=空操作"的 uid 上无效应(1–2,p=1.000)。

**但剩下的部分同样明确,必须一起写:**

3. **没有一卷在其真实原任务上显著跑赢强基线。** KU 只追平直读;TR 跑赢直读但**仍显著输给提示词臂 70.68%**(−10.53pp,p=0.0094);STALE 合计跑赢直读,但 65% 的净增来自**自撰的 dim2_premise**,对应原任务的 dim1_still 只是与直读追平(+6.00pp,p=0.648,该 n 下需 22pp 才判得动),且 oracle 检索直读在 dim1 上 84.00% 仍远高于 66.00%。
4. **原混杂被替换成了三个新混杂**:(a) **基线选择**——TR 上真正的对手不是直读而是一段提示词;(b) **检索命中瓶颈**——STALE dim1 的 −18pp 缺口在检索侧,不在卡片结构侧;(c) **功效不足**——KU n=78、STALE 各 dim n=50,都不足以判 ±6pp 量级。
5. **一个此前完全未标注的噪声底被查出来了,它污染所有单臂对归档的比较。** TR 上同构 uid 探针给出跑批噪声 SD ≈ 3.75pp(95% 带 ±7.36pp),KU 上同库重跑给出 ±1.28pp(答案逐字节相同仅 48/78)。**因此 TR 的 +6.77pp(vs 归档卡片臂)不可与噪声分离**(1.8 SD,符号检验 p=0.0636);KU 轮"同库跑两次 2/2 逐字节相同"是 2 题样本,不可外推。可主张的是增益的**定位**,不是增益的**幅度**。
6. **反向实验没做,这是混杂剩余的最后一块。** 三卷证明了"脏库 → 输",但没有人往干净的 WikiState 库里**注入**碰撞看它是否会掉。缺这一步,"库洁净度是 WikiState 赢的原因"仍只有相关证据。列为下一轮候选,离线注入零 LLM,端到端估约 $1。

**一句话**:混杂在"卡片机制是否比直读更差"这个层面上**已经被完全解释掉了**;在"卡片机制是否比最强基线更好"这个层面上**从未被这三卷支持过,修完之后依然不支持**。修复把一条被误读为机制负结果的证据线,归还成了一条工程缺陷线。

**133 题 / 133 个 uid,每个 uid 恰 1 题。** 因此本卷 **簇 = 题,簇稳健性是恒等操作**;上表"簇自助"实际就是普通的逐题配对自助,clustering 在本卷不提供任何额外保护,也不构成任何额外主张。(与 KU 轮"平均每 uid 1.08 题、簇级≈题级"是同一类情形,但本卷是严格恒等。)

### 5.1 剂量-反应:增益只出现在真的碰撞过的 uid 上

| 分层 | n | 归档 | cardfix | W/L | p |
|---|---|---|---|---|---|
| **碰撞 uid**(`n_segments=2`,修复真的改了图) | 115 | 58(50.43%) | **68(59.13%)** | **13/3** | **0.0213** |

**这是本轮最硬的证据。** 效应精确落在 bug 触及的那 115 个 uid 上,在图同构、只有 id 字符串变了的 16 个 uid 上不出现。对称噪声无法制造这种定位。

### 5.2 机制指标(三项与准确率同向,且在碰撞层上幅度更大)

| 指标 | 全卷归档 | 全卷 cardfix | 碰撞层归档 | 碰撞层 cardfix |

因果链与 KU 轮一致:碰撞把并查集节点折叠成巨型分量,裁决把无关事实当成同一状态链、并大量丢弃真证据(`dropped_n` 20→7);唯一化 `record_id` 后分量恢复,证据留住,答题上下文反而更小(省 19% token)。

### 5.3 新发现的噪声底(**这条推翻了 KU 轮的确定性主张对本卷的外推**)

那 16 个 `n_segments=1` 的 uid 是天然的零成本噪声探针:它们的卡片图与归档**同构**(只是 `r1` → `b0#r1`),union-find 与裁决输出应当逐字节相同。实测:

- **只有 7/16 答案逐字节相同** → 9/16 是读者采样噪声。
- **3/16 判决翻转**(2 降 1 升)。
- 其中 `b29f3365_q1_query` **答案逐字节相同、判官判决从 False 翻成 True** → **判官侧不确定性**。
- (全卷参照:碰撞层 13/115 答案逐字节相同——那里答案本就该变。)

按翻转率 f = 3/16 = 18.75% 外推:133 题上期望分歧对 ≈ 24.9,同配置两次跑批的配对差 SD ≈ **3.75pp**,95% 噪声带 **±7.36pp**。于是:

| 观测值 | 折算 SD | 是否可与噪声分离 |
|---|---|---|
| +12.78pp(vs 直读) | 3.40 SD | **可以** |
| +6.77pp(vs 归档卡片) | 1.80 SD | **不可以 —— 落在噪声带内** |
| 碰撞层 13/3 vs 空操作层 1/2 的方向性不对称 | — | **可以(对称噪声造不出方向性)** |

**结论**:本卷跑批**不是确定性的**。KU 轮"同库同题跑两次 2/2 逐字节相同"这条不可外推到 LME-TR。凡引用本轮 +6.77pp 作为"修复的增量"的地方都要撤回,改引"增益的定位"与"vs 直读的 +12.78pp"。

## 六、对论文的处置

### 作废的

**"LME-TR 缺少可追踪的结构化状态变化,故为适用边界"——这条对 TR 不再成立。** 本卷卡片臂原先低于直读(53.38% vs 47.37%,其实原先已高于直读 6pp;真正低的是被当成卡片臂引用的 rt 45.9 和路由后 40.6),而修复碰撞后卡片臂 60.15% 显著高于直读,且增益精确定位在碰撞 uid 上。凡引用 LME-TR 作为"卡片机制适用边界"证据的地方一律撤回。

**"完整 QVF 在 TR 上 40.6%"这条数字要连同解释一起改口**:40.6 是 v1.2 冻结路由把 81/133 题派给了 rt 臂的结果,是**路由缺陷**(混合形态误派到 rt),不是卡片机制缺陷。v4.2 路由把 rt 换成提示词臂后同卷已到 60.15%。

**"45.9 = 提示词臂"这个读法要全局改口**,它是 rt 臂;提示词臂在本卷是 70.68%。

### 新增的、可主张的

1. **跨批身份保持这条修复在第二个独立语料上复现了"位置正确"的增益**:KU(碰撞 38.51%)与 TR(碰撞 35.95%)两卷,增益都出现在碰撞 uid 上。TR 上还多一个 KU 没有的内建安慰剂对照(16 个空操作 uid 无效应,p=1.0)。这把"分批抽取 + 图结构记忆 → 身份碰撞 → 图折叠"从单卷个案升级为跨语料失效模式。
2. **"永不比基线差"契约在 TR 上以显著幅度达成**:60.15% vs 47.37%,p=0.0115,CI[+3.76,+21.80]。TR 是继 KU 之后第二个由该修复从"追平/说不清"翻成"显著优于直读"的卷。
3. **修复同时省 token**:输入 5,067 → 4,099 tok/题(−19%),准确率反升。修复不是拿成本换准确率。
4. **一个新的写入侧静默失效模式(本卷独有)**:超长条目(≈500k 字符 / 500–600 轮)会让抽取器返回空记录、递归对半分批打到深度上限后放弃,**落盘一个 0 记录的合法卡片库**;读取时静默降级为纯检索,却仍以 `mode="wt_qvf"` 计分,甚至能判对。两个 uid 烧 284k token 换 0 张卡。`QVF_CARD_FAIL_LOUD=2` 正是为此,但归档跑批没开。**任何"卡片臂成绩"都应附带 0 卡文件数。**

### 必须同时写进去的负结果与限定

- **提示词臂 70.68% 仍显著高于修复后卡片臂 60.15%**(p=0.0094)。"对本卷这类混合形态时间推理题,一段提示词优于结构化卡片路线"这条工程规则**不变**。
- **修复对归档卡片臂的整体增量(+6.77pp)统计上不可与跑批噪声分离**(1.8 SD,符号检验 p=0.064)。可主张的是增益的**定位**,不是增益的**幅度**。
- **本卷跑批非确定性**(16 个同构 uid 里 9 个答案变了、3 个判决翻了、1 个是判官自己翻的)。所有本卷单次跑批的点估计都要带这条。
- 归档 `results/wt_cards` 在本卷的碰撞率我复算是 **35.95%**,不是任务书写的 34.7%,差异未查清。

## 七 · 对论文的处置(可主张 / 须收窄 / 须撤回)

**可主张(新增):**

1. **"逐字锚点契约"是可机械校验的,且此前从未被强制过——本轮首次量化了强制它的下游代价。** 在真实人写对话上强制它 **不但免费,还赚 +5.1~+6.4pp 并省 4% token**;在答案逐字植入的合成语料上代价 −1.4pp(不显著)。
2. **一条新的失效模式 + 解**:编造锚点的卡片在图上造伪状态链 → 纯代码裁决误删真证据(`dropped_n` 10.6→4.6)。这对任何"抽取式记忆 + 状态取代裁决"的系统都成立。

### 3.3 "写入侧硬契约"这个声称的最终措辞

原声称不可用(它暗示契约已被强制、且强制有普适收益)。**最终措辞(可直接抄进论文):**

> **写入侧契约的现状与本轮结论。** QVF 的卡片写入路径声明了一条逐字锚点契约(每条记录的 `source_span` 必须是其声明 `source_memory_id` 的逐字连续子串),但该契约在此前所有归档跑批中**从未被强制**(`QVF_CARD_VERIFY_SPAN` 默认为 0)。我们首次对它做了机械校验与端到端剔除对照:违约率为 LME-KU 27.47%(库内指错 14.98% + 全库找不到 12.49%)、STALE-50 28.91%、WikiState 9.45%。剔除违约卡片后,真实人写对话卷上准确率的点估计为 **+6.41pp**(簇稳健 CI[+1.3,+12.8] 不含 0,精确符号检验 p=0.0625——该样本量下 p<0.05 算术不可达),同时读者输入 token 降 4.0%;答案被逐字植入的合成卷上为 **−1.44pp**(p=0.180,簇 CI[−4.1,+1.0])。两臂均满足预注册的非劣判据(点估计 ≥ −2pp 且 p>0.05),据此我们**建议把 `QVF_CARD_VERIFY_SPAN=2` 转为默认**,依据是"非劣 + 真实语料上点估计为正 + 成本更低",**而非"实验证明强制契约更准"**。**收益是语料条件性的**:在答案逐字植入的合成语料上,违约卡片仍双向承载信息,剔除会让聚合算子丢证据。

三条禁写:不得写"硬契约"(它从未被强制);不得写"剔除违约卡片显著提升准确率"(两臂 p 均 >0.05);不得把 KU 的正收益写成普适(S5 上符号相反)。

### 3.4 新增可主张的技术贡献的最终措辞

> **分批抽取系统中的跨批身份碰撞失效模式,及跨批身份保持的修复。**
>
> **失效模式**:当一个抽取式记忆系统把超长上下文分批送入模型建卡、而模型在每批内自行编号记录(`r1, r2, …`)时,跨批拼接若不重编号,同一实体内的记录标识会大量碰撞。若下游用该标识作图节点 id(此处为状态取代裁决的并查集节点),碰撞会把互不相关的事实折叠进同一连通分量,裁决随之把真证据当作"已被取代"而成批误删。
>
> **值多少 / 在几卷上复现**:在三个独立语料上复现,方向一致、机制链一致,且**效应量与碰撞率同向**:
> - LME-KU:碰撞 38.51% → 0%,卡片臂 64.10%→80.77%(15–2–61,p=0.00235,CI[+7.69,+26.92]),`dropped_n` 30.88→10.58;
> - LME-TR:碰撞 35.95% → 0%,60.15% vs 同题直读 47.37%(p=0.0115,CI[+3.76,+21.80]),`dropped_n` 20.07→6.81,输入 token −19%;
> - STALE-50:碰撞 52.75% → 0%,41.33%→56.67%(31–8–111,p=2.94e-4),`dropped_n` 97.81→41.59(误删量约为 KU 的 3 倍,与其最高碰撞率一致)。
>
> **因果证据(不只是相关)**:LME-TR 上带内建安慰剂对照——增益严格落在真实发生碰撞的 115 个 uid(13–3,p=0.0213),而在 16 个"修复即空操作、卡片图同构"的 uid 上无效应(1–2,p=1.000)。对称的跑批噪声无法制造这种方向性定位。
>
> **修复本身是免费的**:三卷上准确率上升的同时答题输入 token 下降(TR −19%、STALE −8.9%、KU 侧同向),不是拿成本换准确率。
>
> **边界(必须同页写明)**:
> 1. **能主张增益的"定位",不能主张增益的"幅度"。** TR 上 vs 归档卡片臂的 +6.77pp 落在该卷跑批噪声带内(SD 3.75pp,95% 带 ±7.36pp,符号检验 p=0.0636),不可与噪声分离。
> 2. **修复只把卡片臂从"劣于直读"抬到"不劣于直读",没有把它抬到"优于最强基线"。** TR 仍显著输给 timeline-CoT 提示词臂(−10.53pp,p=0.0094);STALE 原任务维度 dim1_still 只与直读持平(+6.00pp,p=0.648),且 oracle 检索直读仍高出 18pp。
> 3. **三卷的修复臂是离线派生的上界,不是代码路径的实测。** 内容、槽位、日期、关系边、抽取顺序逐字继承,只唯一化 `record_id` 并同段重映射关系目标;分段边界已用字符预算独立复算证明等于真实顶层批次边界(TR 133/133 恰 2 批、段数 > 批次数者 0 个;STALE 50/50 恰 3 批、49/50 恰 3 段、1 个偏保守),故粒度**不粗于**代码内 `QVF_CARD_RENUMBER=1`,该臂是代码修复效果的上界。`QVF_CARD_RENUMBER=1` 的真实建卡复核只在 KU 上做过 1 个 uid。
> 4. **修复不解决第二个写入侧失效模式**(超长 uid 的 0 卡静默降级,见 C-7),也不解决检索命中瓶颈。
>
> **对外可用的一句话**:*"我们识别并修复了分批抽取式记忆系统中的一类跨批身份碰撞缺陷,它会使图结构裁决把不相关事实折叠、成批误删真证据;修复在三个独立语料上复现,把此前被误认为'机制适用边界'的三条负结果全部归还为工程缺陷,同时降低 token 开销。修复使卡片路线不再劣于直读基线,但不足以使其优于该任务上的最强基线。"*
