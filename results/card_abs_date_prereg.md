# 预注册:写入侧绝对日期回填旗标(QVF_CARD_ABS_DATE,先于跑数提交)

日期:2026-08-20。来源:时序敏感性实验(ed3ab70)附带发现——无 stated_date 的卡片
在读取侧靠"位置型 source_memory_id → 会话日期"回填,会话位置一变连接即断
(伪影轮实测:卡片臂假性塌至 50.0)。

## 修复(冻结文件纪律:env 旗标、默认关、关时逐字节等价)

QVF_CARD_ABS_DATE=1:建卡收尾时,对 stated_date 为空的卡,把其来源会话的**绝对日期**
写入 stated_date(标记 stated_date_from_session=true 以示区分),使读取侧不再依赖
位置回填。默认 0,不触碰任何现有路径。

## 验证与判据(先写死)

- 冒烟:旗标关时 import 与 read 路径行为不变(插入式代码审查 + import 冒烟);
- 效果测试:P108_ext 前 10 库(uid 排序)旗标开重建卡片 →
  在**乱会话卷**(时序实验同一 shuffled 文件,种子 20260820)上跑 wt read(dim4+dim5,20 题):
  1. 修复卡乱会话成绩 ≥ 修复卡原序成绩 − 10pp,且比伪影轮同库成绩高 ≥20pp
     → 脆弱性修复成立,旗标可默认开启列入建议;
  2. 未达 → 记录残余失败模式(可能还有其他位置依赖),不改默认。

成本:建卡 10 库 ~$0.5 + 两次 read ~$0.1。
