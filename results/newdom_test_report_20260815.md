## 2. 判官评分的实际来源与其可信度

跑批各臂**在线内嵌判官**:每行生成后即由 ClaudeJudge(claude-opus-5 默认、全盲、同段代码)判分并写入 `judge_correct`/`judge_reason`。全部 15 个结果文件 **0 条 FALLBACK 行**(判官 API 失败会写 "FALLBACK containment heuristic" 标记,grep 为零)——即凡有 judge_correct 的行都是真实 LLM 判决,而非启发式兜底。

**协议缺口与替代核验**:
- 独立 opus 20 题冒烟复判:**无法执行**(零额度)。替代:对全部 802 条已判行做"金答案包含性启发式 vs 判官"一致性扫描:direct 73.2% / rt 91.7% / wt 75.0% / s5_arm 95.8% / s5_direct 76.8%。低一致率集中在 dim2(金答案为"前提已过时…"模板句,包含性必然误判)与拒答/编造场景。随机抽 12 条分歧逐条目检:**12/12 判官占理**(典型:模型在轨迹中插入编造机构→判官判错而包含性判对;模型先声明无记录再顺带提及金答案→判官判错;dim2 模板金答案不含于自然语言回答→判官判对)。未发现判官系统性偏差证据,但这不是预注册的冒烟复判,额度恢复后应补 20 题正式冒烟。
- 判官模型身份:代码默认 claude-opus-5,.env 无覆盖;但跑批 shell 的运行时 env 无快照,严格说无法事后证明未被 export 覆盖——列为限制(与 STRICT 同性质)。

## 6. 预注册裁决(判据线照录,未挪动)

### 主判据:"新域整体 ≥ 旧域同题型 −10pp 且无题型 <50% → 指控证伪"

**裁决:不成立(指控未被证伪)。** 且此判决对缺失数据鲁棒:P69 S5 三个题型为**完整测量**(75/75 行全存在、全判),28.0/24.0/12.0 全部 <50%,单独即违反"无题型 <50%"子句——任何对缺失格的补测都不能翻转。分层陈述:
- **闭集内 S1-S4(P26)通过**:四题型洁净 95.7/90.5/100.0/94.7,全部高于参考−10pp 线,且全部 ≥50%。键控路由在闭集内迁移成立。
- **S5 即使闭集内也破线**:P26 change_count −15.5pp、longest_tenure −17.6pp(明确破线,非压线);仅 first_vs_last 通过。
- **闭集外 S5 崩溃**:P69 三题型全 <50%;P1303 change_count −11.3pp(截断样本 n=18,按不利于系统方向如实计破线)。
- **P69/P1303 S1-S4 无法裁决**(洁净覆盖 12/100、12/31)。

### (a) 闭集内(P26)vs 闭集外(P69/P1303)差距 >15pp → 键控泛化声称撤回

**裁决:触发,键控泛化声称撤回(降格为"闭集内成立")。** 决定性证据来自完整测量的 S5:P26 78.7 vs P69 21.3,差 **57.4pp**(>>15pp)。P1303 S5 72.2(截断)介于其间;S1-S4 洁净子集方向一致(95.3 vs 75.0)但 n 不足,不单独作数。遥测独立佐证:别名命中 90.0→26.0→3.2%,空证据 2.7→70.7%。裁决主要由 S5 承载,S1-S4 侧的闭集内外对比留待补测——但 15pp 线已被完整格击穿,撤回不待补测。

### (b) 盲写题 vs 对照桥题差距 >8pp → 现有成绩标注模板膨胀

**裁决:未触发(在可测子集上无模板膨胀证据)。** 模板膨胀的指纹应为"桥题(旧模板同构)显著高于盲写题"。实测(系统行、洁净子集,盲写−桥):合并 +8.0pp(盲写 70.0 vs 桥 62.0,方向与膨胀相反);分层 S1-S4 −0.6pp(桥 94.1 vs 盲写 93.5,n_桥=17,差异在噪声内)、S5 +8.6pp(桥 45.5 vs 盲写 54.1,盲写反而高)。合并数含域构成混杂(桥题在低分域占比同为 20%),故以分层为准:两层均无"盲写更差 >8pp"。**覆盖注记**:P69/P1303 的 S1-S4 盲写行大量缺失,本裁决对 S1-S4 层仅在 P26 上充分;S5 层完整。

### (c) 编译 ok<90% 或空计划回落 >20% → 编译器不迁移

**裁决:编译层迁移成立;执行/键控层在 P69 不迁移(按第二种操作化触发)。** 两种读法如实分列:
- 按字面"编译 ok"与"空计划":compile_ok 100%(≥90% 通过);编译器从未产出空计划,空计划回落 0%(<20% 通过)→ 字面判据**未触发**。few-shot 域外改写的独立证据(paraphrase 测试,commit 9410c11:1107 改写 haiku 100%)同向支持编译层迁移。
- 按机制等价操作化(计划非空但执行空手而归,evidence_n=0,读者被迫无证据作答):P69 70.7% **>20% 触发**;P26 2.7%、P1303 11.1%(截断样本)未触发。即:**编译器把 'school' 正确编译成了计划,但计划里的 slot 键在键控店内无货**——不迁移的不是编译器,是槽位键控闭集。这与裁决 (a) 是同一根因的两个测量面。
