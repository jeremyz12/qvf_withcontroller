# QVF — 查询条件化的记忆时效守卫(零训练)

> 当前发布:**时效版**——覆盖的失效物种为"时间性替代"(旧状态被新状态取代后仍被当作现状)。发布配置为三层栈:查询风险门 → 摘除式过滤 → 死路定向升级(见"发布配置"一节)。

本仓库是 QVF 的当前版本(2026-08)。旧版符号引擎保留在 `legacy_engine/` 作为语义参考实现与契约校验器;现行版用约 30 行可读规则替代了它,并新增了查询时间范围门控。更早版本的完整代码与文档见 git 历史(提交 441103c 及之前)。

## 它解决什么问题

长期记忆助手的一类特定失败:**把旧状态当现状说出来**(用户 3 月说住达尔文、6 月说搬去墨尔本,9 月问"我现在住哪"时答达尔文)。QVF 是检索后、生成前的守卫:识别查询意图,把已被取代的旧状态从上下文中物理移出,其余场景近似直通。

## 流水线

```
查询 + 记忆库
  → 稠密检索 top-10(nomic-embed-text,本地)
  → LLM 跨度锚定抽取(claude-haiku-4-5,每题一次调用)
      产出:查询焦点(实体/槽位/是否问现在/时间范围)
           + 逐条记录(逐字原文出处、值、替代关系标签)
      规范:仅显式改变语言才算替代;拿不准标 unresolved
  → 范围门控:past_or_change 查询 → 完整上下文直通(历史是证据不是噪声)
  → 轻规则裁决(~30 行,零 LLM):
      有替代 → 保新删旧(物理移出上下文)
      竞争值无显式语言 → 都保留 + 冲突提示词
      无冲突 → 放行;无记录 → 回退全文
  → 有效性触发补检索(问现在但没找到新状态时,一次,最多补 5 轮)
  → 读者作答(claude-haiku-4-5;--reader 可换任意 Anthropic 型号)
```

设计原则:**LLM 只做符号够不着的语义解析;所有决策程序是可读代码**。每个被删的记忆轮都能回溯到"哪条记录、哪个规则";证据只删不改写(零幻觉风险);改策略=改一行代码。

### STALE-Chain:多状态链扩展基准(自建,CC BY 4.0 衍生,held-out 主表)

STALE 每题只有 A/B 两段记忆,易被质疑"二选一"。STALE-Chain 把单属性扩展为 **3-5 个带日期状态的演化链**,埋入原 STALE 干扰会话(~33 会话/条),四个探测维度:当前态 / 中间态前提陷阱 / **点时刻**(问两次更新之间某日期的状态,直读几乎必错)/ **轨迹**(问怎么变的,需完整有序链)。生成 opus + 确定性验证器(逐字 span 存在、日期严格递增、值两两互异、点日期落在区间内),60 生成 53 过验。开发在 12 条 pilot,**下表为 53 条 held-out 首踏,848 行零错误**:

| 维度(各53) | 直读 | 纯指令² | 注记不过滤¹ | 全上下文直读³ | top10+QVF | **全上下文+QVF** |
|---|---|---|---|---|---|---|
| 当前态 | 37 | 38 | 17 | 50 | 38 | **52** |
| 前提陷阱 | 11 | 14 | 6 | **6** | 18 | **21** |
| 点时刻 | 15 | 17 | 8 | **9** | 36 | **44** |
| 轨迹 | 21 | 23 | 0 | 48 | 35 | **49** |
| **合计(212)** | 84 (39.6%) | 92 (43.4%) | 31 (14.6%) | 113 (53.3%) | 127 (59.9%) | **166 (78.3%)** |
| 输入tok/题 | 1.4k | 1.5k | 6.5k | 24.7k | 16.4k | 52k |

配对(均一侧符号检验):top10+QVF vs 直读 **44胜1负 p=1.3×10⁻¹²**(条目级聚类重检 31胜1负 p≈10⁻⁸ 仍决定性;跨家族判官 gpt-5-mini 复判一致率 97.9%,其下 48胜2负 p=1.1×10⁻¹²);**全上下文+QVF vs 全上下文直读 56胜3负 p=6×10⁻¹⁴**、vs top10+QVF 54胜15负 p=1.3×10⁻⁶。dev 64.6%→test 59.9%(top10版),分维结构保持。

**正交性发现(本表的机制主线)**:上下文量与有效性裁决是两条独立轴——全上下文治**召回型**失败(轨迹 21→48)却**放大裁决型**失败(前提 11→6、点时刻 15→9:过时状态全摆在眼前,前提采纳与近因混淆加剧);QVF 恰治后者;组合叠加,直读→组合 **+38.7pp**。

² 纯指令对照 = 直读 + "注意过期状态"一段话指令。**+3.8pp 温和有益**——提示词不是毒药;但裁决在其上另有 +16.5pp(species2 vs 纯指令 37胜2负 p=1.4×10⁻⁹)。
³ 全上下文直读 = 整个 haystack 进提示词、无检索(怀疑者的 iso-cost 基线)。

¹ 更正(内部评审轮发现此前标注有误):该对照是**注记不过滤**臂——旧引擎产出与 QVF 同源的有效性标注(哪条可用/哪条过时),以 JSON 包形式放进阅读器提示词,但**不做物理删除**。它比裸直读还低 25pp、轨迹 0/53:弱阅读器连完整的有效性注记都利用不了,反而被"过时"标签带偏丢弃历史状态——**交付方式(物理减法 vs 提示词内注记)本身是决定性变量**。纯指令对照("注意过期状态"一句话直读)另行补测,结果见下方更新。

链版新增组件(全部 dev 上逐条法证驱动,代码规则非提示词):链补全检索(值线索二次检索,优先合并早于已知最早态的会话)、**兄弟轮扩展**(真状态常在链记录同会话邻座轮,零嵌入)、**识别扫描**(代码日期窗口过滤+抽取器语义识别,治"keto 不含 diet 一词"的嵌入盲区;链空时是从零建链的唯一机制)、**确定性点时刻裁决**(代码做 `state.date ≤ 问日期 < 下次变更` 区间算术,注记明示"这就是答案")、合并守卫(不缩短则替换、缩短则并集吸收)、注记包含式去重。

### 外部基准扩展评估轮(2026-08-04;试点轮 n=50 seed 42 → 确认轮 n=200 seed 202608)

判决式汇总(确认轮为准):

- **TempReason L2(ACL 2023,维基实体时序状态,月粒度)——两个配置均显著净胜**:干净 fact_context 版 n=200:species2 **99.5% vs 直读 95.0%,9胜0负 p=0.002**(零损失);**原文模式**(状态埋进文章散文、句级切块)n=200:直读崩至 **30.0%**,species2 **38.0%,19胜3负 p=4.3×10⁻⁴**(点时刻路 147/200 触发)。外部公开基准的显著净增益成立,机制条件=感知困难,与 STALE-Chain 一致;
- **HoH-QAs(ACL 2025,真实维基编辑差分,11.2 万条,新旧版本各带时间戳)**:核心结果是**删除时间健全性检查的消融**——无检查 74%(方向混淆把当前版本连同过时版本一起删,14/50),有检查 **100%,误删清零**。净增益预注册合并 n=400 判决:8胜3负 p=0.11 **不显著**(两批分别 6胜1负 / 2胜2负,如实披露,不追加批次);消融结论不依赖 p 值;
- **LoCoMo 第 5 类对抗题(诱导性不可答陷阱,n=446 全局最大未测切片)**:直读 92% 已饱和,无增益空间;暴露并修复一个真缺陷——**集合槽(兴趣类)被"最新者胜"当单值裁决制造错误答案**(slot_cardinality 规则,0胜2负→0胜1负);弃答守卫在单跳害控上 0胜0负**零误伤**;
- **MemConflict 全量 150(预注册分层)**:dynamic 6胜4负平;static 1胜5负、conditional 0胜3负——两条预注册"会受伤"预测证实,**方法边界=时序更新型失效**,错误信息型/条件绑定型需要矛盾裁决路与条件绑定路(未覆盖,limitation)。

跨基准规律(论文级):**现代读者在"干净状态+少干扰"配置下自行饱和(92-97%),QVF 的增益集中于状态深埋长噪声历史的场景**——适用边界本身是发现。TempReason 干净版的例外说明另一半机制:即便读者近饱和,确定性区间算术仍能把日期比较错误清零(9胜0负)。

**重复性**(同种子同代码重跑 TempReason n=50 两臂):答案逐字相同 43/50(直读)与 38/50(species2),判分翻转 **0/50**,聚合准确率逐位复现。LLM 层措辞会漂,结论层稳定;长答案基准保守预算 ±1-2 题/50。规则层(删除/区间/注记)完全确定。

判读:

- **四格里三格统计显著**。两个改写认知的发现:(1)推理读者在陷阱上并不比弱读者强(直读 29% vs 31%——照样掉坑),但**利用 QVF 交付证据的能力**强得多(+16.4pp vs +8.5pp)——增益 = 交付证据质量 × 读者利用能力,不是单调的"读者越强越无用";(2)T2 上分层:弱读者只能吃手术路(隐晦措辞很少触发→不稳定),推理读者连"保留双方+冲突提示"路也能吃(T2 仍显著);
- **泛化基准双提供商统计中性**(|净胜负|≤3),不伤害目标达成;
- **已证伪并放弃的扩展**(全部预注册、新鲜切片或零成本反事实):规则扩展包(净负)、聚合守卫(无净益)、强制枚举召回契约(7胜8负)、兄弟轮扩展(当时不显著;后在 STALE-Chain 语境下以"链记录同会话邻座轮"形式重新验证生效)、写入时台账(无增益且摊销失败)、"强证据才干预"保守策略(反事实 gpt 档 -92 题)、朴素组件叠加(13胜23负)、残局分路(对升级单独版 10胜11负持平)、槽位定向补检索(捕获率 34%→41% 但终局 5胜3负边际)、**TR/MC-dynamic 泛化净胜声明**(dev 5胜0负 / 3胜0负,全量新鲜切片 4胜4负 / 6胜4负——dev 假象,已撤回)、**无日期分级软注记**(TempReason-raw 38%<44%,净输 4 题:硬注记的读者服从价值大于日期不完整风险)、**同义词焦点救 chain=0**(12→11,死因是证据不在检索窗口而非词汇)、**物种契约第一版**(矛盾/条件/终止三物种——MemConflict 上新路仅触发 4/50,76% 的题被范围门控先行放行,词汇扩充不改变感知,1胜2负未生效;扩物种需先修门控对"偏好/事实现状"类问题的判读与冲突对召回)。**第二版(species2)复测后采纳**:修复触发率(轨迹路 38/50 触发)后,MC dynamic 层 3胜0负、总分 56%≥v5;准新鲜 T1(条目 105-144,首踏)55.0% vs v5 49.2%(13胜6负),与首个 T1 切片合并 29胜13负 p≈0.020 过显著线,全场无伤害——采纳为标准抽取契约。新增能力:变化轨迹问题(how did X change)获得按日期排序的状态链注记;状态终止标签生效。矛盾/条件两物种仍未生效(召回不足),维持未覆盖;
- 对推理读者(gpt-5-mini)定向升级无增量(T1 45.7%≈45.5%):升级修复的是路由质量,推理读者自身已在补偿脏标签——增益=证据质量×读者利用能力的又一验证;
- 早期 n=20 pilot 与"连续段=随机样本"的假设都曾误导(git 历史可溯),现行结论全部基于 n≥150、随机/全量抽样、题型分层。

vNext:门控前置(离线验证中)、repair 增量抽取(成本 -60% 候选)、疑难查询定向升级抽取器、条件化调用全案。

## 数据

## 目录

- `qvf/engine_bridge.py` — 抽取契约(Pydantic schema + 提示词,含 stated_date 文本内日期字段)、范围门控 schema、旧引擎桥接、本地读者支持、补检索
- `scripts/gen_stale_chain.py` — STALE-Chain 生成器(opus 生成 + 确定性验证器)
- `eval/stale_chain_dataset.py` / `eval/tempreason_dataset.py` / `eval/hoh_dataset.py` — 链基准与外部基准加载器
- `qvf/retrieval.py` — BM25 与 Ollama 稠密检索(带缓存)
- `qvf/judge.py` — LLM 判官(含降级回退标记)
- `scripts/run_decisive_stale.py` — 全部实验条件的运行器(dense_direct/minimal_rules_v5/extraction_only/oracle 等;--sample-n 随机抽样)
- `scripts/rejudge_fallback.py` — 降级判分的重判工具
- `scripts/judge_audit_server.py` + `judge_audit.html` — 人工判分盲审网页
- `legacy_engine/` — 旧版确定性有效性引擎(参考实现;engine_bridge 自动发现,或用 QVF_ENGINE_SRC 指定)

研究代码;逐行结果带 extractor/reader 模型 ID 与 token/延迟字段以保证复现链与成本核算。
