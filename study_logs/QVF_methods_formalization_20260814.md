## §1 记号与库定义

**定义 1(时态事实库)**。用户 u 的记忆库是有限记录集

```
S_u = { r = (o, s, v, t, σ, ρ) }
```

其中 o ∈ O 为属主(owner),s ∈ Σ 为槽位类(slot_class,七类闭集),v 为状态值,t 为陈述日期(stated_date,允许部分日期 YYYY / YYYY-MM),σ 为出处锚点——**约束为会话原文的逐字连续子串**(可由字符串包含关系机械校验),ρ 为替换边(supersedes,指向被本记录取代的记录 id 或 ⊥)。另有标签函数 g: r ↦ 2^T(value_tags)。

**定义 2(键与链)**。键 k = (o, s)。记 S|_k 为键 k 的记录子集,按 t 升序排序并合并相邻同值后得**状态链**

```
chain(k) = ⟨(v_1, t_1), …, (v_m, t_m)⟩,  t_1 < ⋯ < t_m,  v_i ≠ v_{i+1}
```

链上第 i 段的有效区间为 [t_i, t_{i+1})(右端开,最后一段为 [t_m, +∞))。

**定义 3(键控深度与库形态)**。

```
d(k) = |chain(k)|            (键控深度:该键的历史状态数)
D(S) = max_k d(k)            (库形态:整库最大键控深度)
```

一人称问题的深度计数限定 o ∈ {"", "user"}(防多人库把不同属主的同类状态并成假深链)。

## §2 核心命题:有效性是二元函数

**定义 4(查询条件化有效性)**。设 Q 为问题空间。记忆的有效性不是一元属性 valid(r),而是二元函数

```
valid : S × Q → {0, 1}
```

同一条旧记录,对"问现在"是污染(应被排除),对"问过去某天"是唯一正确证据,对"问变化全程"是必要成分。任何写入时固化的一元有效性标记(取最新、打过期标签)在定义上只能答对一类问题;该缺陷的实测定价:查询盲"最新值优先"策略 32.0% vs QVF 86.5%(+54.5pp,系其明言不做的题型的覆盖代价)。

## §3 读取侧:问题编译与查询计划

**定义 5(查询计划)**。编译器 C(小模型单次调用)把自然语言问题映射为严格 JSON 计划

```
C : Q → P,   p = (op, k, args),   op ∈ OPS(11 算子闭集)
```

计划由纯代码执行器 E 在 S 上求值,产出证据包 E(p, S);读者模型只见证据包与计算结论行,**不做任何计数或日期算术**。金答案不进入 C 与读者的任何输入(只进判官)。

## §4 算子指称语义(11 算子)

以下 ⟦·⟧ 均为 chain(k) = ⟨(v_i, t_i)⟩_{i=1..m} 上的函数;计数族算子先经算子条件化卫生过滤 H(见 §4.1)。

| 算子 | 语义 | 备注 |
|---|---|---|
| `current` | v_m | 链尾值 |
| `point_in_time(d)` | v_i s.t. t_i ≤ d < t_{i+1};d < t_1 时为"早于已知最早状态" | 右开区间 |
| `trajectory` | 全链 ⟨(v_i, t_i)⟩ | 逐条带日期输出 |
| `premise_check(v̂)` | 若 ∃i<m: v̂ = v_i 且 v̂ ≠ v_m → 判"前提过时",输出 (v̂ 的有效区间, v_m);若 v̂ = v_m → 前提成立 | 答前算子,非答后审计 |
| `count_changes` | m − 1 | 状态变更次数 |
| `count_before(d)` | \|{ i ≥ 2 : t_i ≤ d }\| | d 前的变更次数 |
| `first_last` | (v_1, t_1) / (v_m, t_m) | 按问句取首或末 |
| `longest` | argmax_v dur(v),dur(v) = Σ_{i: v_i=v} days([t_i, t_{i+1})) | 同值多段闭区间累加口径 |
| `tag_filter(g₀)` | { r ∈ S : g₀ ∈ g(r) } | 跨键;逐条带日期与锚点 |
| `tag_trend(g₀)` | 按年分桶 \|{ r : g₀ ∈ g(r), year(t_r)=y }\| 的序列 | 语义上卷 |
| `join_at_change(s₂; a)` | t* = 锚定日期(k 上第 a 次变更或值锚命中);答 ⟦point_in_time(t*)⟧ 于键 (o, s₂) | 序数锚/值锚双形态 |

### §4.1 算子条件化卫生过滤

```
H(pool, op) = pool                              若 op ∉ COUNT_OPS
            = dedup_session(drop_datephrase(pool))  若 op ∈ COUNT_OPS
```

COUNT_OPS = {count_changes, count_before, first_last, longest}。理由(实测方法学发现):一张碎卡对点查无害(点查取区间命中,冗余卡不改变命中值),对计数是 ±1 的直接错误——**去噪必须条件在下游算子上,全局清洗会改变点查语义**。

## §5 路由决策函数与三个算法框

**定义 6(四臂路由)**。路由是决策函数

```
π(q, S) ∈ {direct, prompt, cards, extract}
```

现行 v4.2 为规则式(伪代码见 Algorithm 2):非时序/事件算术 → direct;时序薄(d(k_q) < θ)且整库皆浅(D(S) < θ)→ prompt;历史厚 → cards;残余 → extract。θ = 3(该阈值的"为什么是 3"由 §7.1 的学习路由+证书回答:阈值不再是人选的,是带 (ε,δ) 保证的校准输出)。

**Algorithm 1(写入:批量建卡契约)**
```
输入: 用户 u 的新会话集 {(text_j, date_j)}
1: cards ← LLM_cheap(contract_prompt, sessions)   # 单次批量调用
2: for each card: assert card.σ ⊑ text_j          # 逐字子串校验,违约丢弃
3: 近同值独立宣告规则(严格覆盖契约): 显式就任宣告独立成卡
4: S_u ← S_u ∪ cards; 维护 ρ(supersedes)边
输出: S_u(JSON 事实表)+ 用量记账
```

**Algorithm 2(读取:路由)**
```
输入: 问题 q, 库 S
1: (scope, k_q) ← focus(q)            # 聚焦调用,~0.3k token
2: if ¬temporal(q) ∨ arith(q): return direct
3: if d(k_q) < θ ∧ D(S) < θ: return prompt
4: if d(k_q) ≥ θ: return cards
5: return extract
```

**Algorithm 3(读取:编译-执行-作答)**
```
输入: 问题 q, 库 S
1: p ← C(q)                            # 编译,严格 JSON,三次重试
2: pool ← H(select(S, p.k), p.op)      # 算子条件化卫生
3: evidence ← E(p, pool)               # 纯代码执行,零 token
4: answer ← LLM_reader(q, evidence)    # 读者被约束逐条带日期引用
输出: answer + 证据包(每行含 [日期] 值 — "逐字锚点")
```

## §6 成本模型与两条形式化主张

**每题读取成本**:c(q) = c_focus + c_compile + c_reader(|E(p,S)|)。

**主张 A(成本平坦性)**:|E(p,S)| 由链长 m 与算子输出界定,与问题难度等级无关——S1 点查与 S7 上卷同价位(实测 ~1.7-2k token/题)。难度升级涨在计划语义上,不涨在 token 上;对照:直读/现场抽取的 c(q) 随库规模线性增长。

**主张 B(写入摊销)**:库 S 建档成本 W(S) 为一次性预付,被问 N 次后每题含摊成本

```
c̄(q) = c(q) + W(S)/N
```

W(S) ≈ 语料一次读入(信息论下界:任何系统至少读每条记忆一遍);对现场抽取(19-43k/题)第 1 题回本。每题一库形态(N=1)摊无可摊 → 由 Algorithm 2 的库形态条件自动改派 prompt 臂,即**写入成本本身也被路由管理**。

### §7.2 P1:算子族的最小完备基(**08-16 已兑现,终裁版**)

> **命题 2(成立)**:原语集 **P = {SELECT, TAGSET, WINDOW, PICK, ASOF, AGG}**,|P| = 6,使 §4 的 11 算子均可表示为深度 ≤ 3 的 P-表达式。构造性证明 = 宏定义表(见 study_logs/QVF_P1_completeness_20260816.md)。

**终裁要点(取代原"候选"表述)**:
- **JOIN_T 不是独立原语**——跨槽位 join 被 ASOF 的表达式日期参数吸收:`JOIN_T(e₁, e₂) ≡ ASOF(e₂, at=e₁)`。省一个原语且类型更干净。原文写的 `NTH` 定名为 `PICK`(序数或值锚取元,`exclude_last` 承载 premise_check 的过时值语义)。
- **机器可检**:宏执行 vs 平面执行证据包**逐字节等价 347/347**(终裁现场零信任复跑:S5 全量 314 + S6 33);另有历史记录 S5 synthetic 316 + S7 切片 50 转引未现场复核(审计缺口已记)。编译良构率 67/67 = 100%。
- **措辞纪律三条(违反即被抓)**:①只能说"**原语类型数 |P|=6 零膨胀**",不可说"零代码"(dev 轮 2 给 WINDOW 加了 7 个可选界字段、AGG 加了 `count_elements` 枚举,约 60 行,与代码注释可对质);②**`JOIN_T∘WINDOW` 是真实反例**(需对 WINDOW 切出的每段分别求值再跨段比较,现有原语任何填法都表达不了,已由 `scripts/wsc_s8_inexpressible.py` 标 NOT expressible),不可说"新题型 100% 覆盖";③代数臂只能主张**表达力更强**(平面臂结构性不可表达率 77.6%),**不可主张更准**——S8 未见组合上代数臂 49.3% 低于平面臂 52.2%,猜想被否定(根因为证据包渲染缺陷,非表达力缺陷)。

推论:新题型 = 新组合,算子族不随题型膨胀;配组合泛化实验(未见组合 split)。
