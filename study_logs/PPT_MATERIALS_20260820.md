# 第一部分 · 问题出处(3–4 页)

## 页 1:现象——失效不是忘了,是记得太多、选错版本

- 同一条"我住墨尔本"的旧记录:对"我现在住哪"是**污染**,对"2022 年住哪"是
  **唯一正确证据**,对"搬过几次家"是**必要成分**
- 形式化:`valid : S × Q → {0,1}`——一条记忆过不过期是(记忆,问题)对的函数

## 页 2:两个铁证(自测,同题配对)

| 实验 | 结果 |
|---|---|
| **整库全放进上下文**(15.4× token,检索因素彻底消除) | 聚合题 **50.5%**,与最小预算不可区分(χ²=0.47) |
| 计数题("我换过几次工作")稠密检索直读 | **9.1%** |

讲稿:"瓶颈不是找到信息,是不知道哪些记录构成答案集。"

## 页 3:领域现状与缺口(引用的论文全部核实过)

| 论文 | 它做的 | 它留下的 |
|---|---|---|
| **Zep**(时序知识图谱记忆) | 双时态失效标记,115k→1.6k token | 失效判定是 LLM 二值比较;**无多值/集合语义**(全文零提及) |
| **A-TMA**(arXiv 2607.01935) | 状态角色标签 + 四类查询画像 | 每槽恰好两态;**k≥3 链、集合值、回退在表示层不可写** |
| **TReMu**(Findings of ACL 2025) | 写入时推断日期 + 符号执行时间算术 | **记忆库自身正确性从未被测**;错误不归因库/推理 |
| **2601.00821** Fidelity Before Structure | 同管线只换存储表示:**逐字块胜抽取产物 15.9–22.0pp** | 顶在所有"抽取式记忆"的前提上——**必须正面回应** |
| **2607.16019** 呈现混淆(render confound) | 同机制换排版:+0.182 → **+0.021** | 领域评测普遍未控呈现——我们全部同题同读者 |
| **2606.15017** 预算匹配基线 | token 匹配的朴素基线追平三种记忆增强 | **我们实测了它的边界**:聚合题型上预算收益为负 |
| **2606.26511** Temporal Validity | 单值 supersession 97% 可靠 | **多值句上抽取塌到 44%,把基准隔离弃用**——集合语义是公认空位 |

## 页 4:缺口陈述(gap)

> 已有工作要么假设**单值替换**(Zep/A-TMA/2606.26511),要么不测**库自身对错**
> (TReMu),要么被证明增益来自**呈现与提示词**(2607.16019;MAGMA 头条优势
> 99% 来自一条指令——我们的全文精读)。
> **没有工作把"哪些记录构成答案集"作为显式、可判分的产物来定价。** 这是 QVF 的位置。

## 页 7:工作二 · QVF 是什么(一页架构)

写入:对话 → 六字段状态卡片(值/日期/逐字锚点/替换边/属主/**槽位基数**)→ 按(属主,槽位类)成链
读取:问题 → 编译(op)→ **筛选该用的记录 → 认证每条的角色 → 需要时代码计算** → 读者渲染
+ 本周新增装配层:成员过滤(语义角色+确定性授权)/ 集合语义分叉 / 空证据回退 / op 路由

定位句:**把"哪些记录构成答案集"从读者的隐性负担,变成显式、可机械检查的产物。**

## 页 9:边界一 · 题型分野(跨三语料稳定)

## 页 10:边界二 · 受控孪生实验(值语义)

同生成器/同干扰池/同读者,唯一变量 = 值语义(替换 vs 集合):
- 卡片臂 − 提示词:替换批 +1.14 [−5.68,+7.95] / 集合批 **−11.70 [−19.15,−4.79]**
- **主优势出不了原考场**:编译臂在替换孪生上反输直读 9.7pp → 引出保真度诊断
⚠️ 单种子,标"初步受控证据"

## 页 11:发现 · 链污染与表面信号的系统性失效

- 诊断:**43% 链尾错误**,污染是"同主题、错属性"(饮品单混进咖啡店链——放原例)
- 溯源信号(锚点/ID/边):伪卡**全满分**
- 内容表面信号:锚点合规差 **+0.009(全瞎)**;嵌入一致性**反向 −0.094**
  (污染物恰好主题邻近)
- **结论:成员资格是语义角色判断,表面信号(两级)够不着** —— 负结果,已入档

## 页 12:修复 · 装配层三件套(全部预注册、金链机械判分)

| 修复 | 机制 | 效果 |
|---|---|---|
| **成员过滤**($0.08/库一次小调用) | 语义角色问句 + never-infer + **确定性授权**(引文钉回锚点) | 链精度 0.56→**0.88**;编译臂 57.4→**67.05,追平直读**(p<0.001) |
| **集合语义装配**(slot_cardinality 下游分叉) | current/point/count 三算子按多数基数切换 | 集合批编译臂 37.2→**75.0,追平直读 72.3**(泄漏审计后口径);计数题 vs 直读 **+14.9pp** |
| **空证据回退**(fail-closed 完成形) | 空证据整题改走直读 | 三语料重放 +6.8 / **+36.7** / +44 |

方法来源如实标注:K=1(ConsistencyGate 消融)/ never-infer(Schema-Grounded)/
确定性授权(StateAuditor VTA)——组件有出处,**组合与判分是我们的**。

## 页 13:发现 · 断言与展示的交叉条件
