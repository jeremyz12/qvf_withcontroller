## 一、目的与叙事框架

**一句话**:现有记忆模块对**时序感知不敏感**——它们把"有效性"当作记忆条目写入时的
属性;QVF 把它改成**查询时相对 (state, query) 对的判定**,并为此付出的每一段结构
逐段定价。(叙事框架为导师 2026-08-20 组会认可的定位。)

四个证据支柱把这句话变成定量事实:
- **感知缺失存在**:整库直读某日状态 38.2% vs 卡片臂 94.5%(+56.4,p=1.4e-13);金链
  直给仅 15.1——信息在场,读者感知不到;
- **感知的载体**:整库乱序 85.5→37.3(−48.2,p=5.7e-12)→ smw −6.0(p=0.006)→ smoc
  −2.6(n.s.)→ 卡片臂 +0.9——时序感知从"上下文位置"逐级搬进"日期字段"再到"代码";
- **感知失败的普遍性**:16 系统同台,主流记忆系统 1.7~63.3,写入时盖章台账 11.7
  (机制保证的天花板 71.6pp);
- **感知可恢复且可定价**:选择/规范化/认证/计算逐段配对显著(v1 与 v2 双考场)。

## 二、三条不可让渡主张(论文主轴,硬约束)

1. **valid: S×Q 查询时判定**——竞品全部写入时盖章;天花板的*测量*是我们独有的。
   锚点:QVF_methods_formalization_20260814.md §2 定义4;MemStrata 式台账 11.7@60 题
   (repro_batch4c_verdict.md)。
2. **构念级逐段定价方法学**——同一批证据换呈现形态、逐段配对检验,不是组件消融。
   锚点:v1 三段 +18.4/+11.2/+6.5(REPORT_SAFE_CLAIMS ①);v2 复现 +14.06(p=1.5e-08)
   /+2.95(p=0.036)/+10.24(p=1.8e-09)(opt_batch11_verdict.md)。
3. **链条件归因+边界+修复闭环**——错在库还是执行,wrapper 类测不了。
   锚点:两药治疗 68.2→93.2(p=0.00098,opt_batch5);污染识破 100%/误删 0.7%/恢复
   +9.2 p=0.019(opt_batch6);词表根治孪生 +18.2(同上)。

**分界轴 vs StateMem(借用协议的所有权界定)**:smoc = QVF 账目(ours)+ StateMem
F.1 读法(cited 消费端)。同一读法吃原文 13.9k tok/题,吃账目 2.5k;v1 +3.35(p=0.11),
v2 +1.39(p=0.50 n.s.)→ **现行口径:同精度、读取成本 1/5.5**;乱序四点位阶梯与
可归因性为另两条分界。趋同是投降,防线即分界轴。

## 四、基准:WikiState

**构建配方**(W4_wikistate_design.md):Wikidata 属性历史(P39/P108/P54/P551,
P580/P582 起止限定符),链 ≥3 态,机械抽取+校验(不重叠、严格递增),**零人工金标**。
防污染三闸:参数可答排除(无记忆对照)、长尾实体优先、化名变体。记忆化:每态由
opus 渲染成带日期第一人称会话 + STALE 干扰会话;逐字锚点+日期校验器锁值。
题型:当前值/中间陷阱/点查/历程聚合(change_count、count_before、longest_tenure、
first_vs_last)。

- **v1**:105 链 / 418 聚合题;**v2**:144 链 / 576 题(店不动只换题,零 LLM 确定性生成);
- **v1 三缺陷与 v2 修复**(wikistate_dataset_audit_20260824.md;opt_batch6 P④,$0):
  ①金答案偏斜(常数基线 66.7%)→ 贪心锚点配平至众数 ≤35%(66.7→30.6/20.8);
  ②longest_tenure 链尾捷径(末段计 0 天,gold=链尾值 0%)→ 末段计到 Today,链尾胜率
  0→24.3%;③change_count N/N−1 歧义 → 约定写进题面。修复过程公开,"考场自审并修复"
  本身入论文;
- **孪生语料**(set_vs_replacement 实验 C + 多种子):唯一前瞻因果试验;集合半边证实
  负向(卡片−提示词 −11.7),替换半边意外零效应 → 界定"逐字植值+干净日期"为隐性前提,
  入 limitations;多种子 +5.1/+5.6/+5.6(合并 CI [+0.40,+10.08])摘"单种子"帽;
- **人工核验**(2026-08-26 终版):单项目"Chain Verification (full coverage)"——
  144 链全覆盖 + 5 催化剂题(日期偏移/删行/值互换/伪造锚点/伪造加行),每题 3 份,
  8 人×60 题;评审见链表格+全量原始日志(锚点高亮);产出 Fleiss' κ、一致率、
  催化剂通过率、分歧裁决 → 数据集 v2.1。域名 rate.wikistate.org(HTTPS,待 DNS)。

## 六、机制定价与稳健性

**选择阶梯**(全 418 口径,唯正则级 100 题子集星标):
正则 20.0* → 检索 47.61 → 语义选对 60.29(+12.7,p=9.5e-06)→ 规范化 66.03(+5.7,
p=0.0079)→ 认证 77.27(+11.2,p=4.8e-08)→ 计算 83.73(+6.5,p=4.9e-05)。
链条闭合:47.6 + 18.4 + 11.2 + 6.5 = 83.7。

**稳健性集合**:乱序阶梯(−48.2 → −6.0 → −2.6 → +0.9);风格配平+40 硬负例不击穿
(编译 92.9→89.3 p=1);身份泄漏否证(S5 1/144,Fisher p=1);判官交叉审计零偏袒
(102/102,分歧 2.7% 且 5/7 压我方);孪生泄漏审计(集合"反超"降"追平",过滤增益
干净层反而 +34.7 加强);全族错误控制(142 条入 α 族,核心主张全部双口径存活,
45 双存活/33 仅 FDR/降级仅 3 条旁支)。

**成本诚实口径**(cost_usd_ledger.md):唯一可说 = "同读端预算 +33pp"(QVF 读端
$0.00242/题 vs 整库 50.5%)+ "建卡 $6.14 一次性随复用摊薄"(4 题/库 $0.017/题,
20 题/库 $0.0054);整库挂缓存后 QVF 全口径 2.8× 更贵,如实报。账目 vs 原文:
同精度 1/5.5 读取成本(v2)。
