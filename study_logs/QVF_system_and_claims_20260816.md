# QVF:系统现状与可声明的创新(2026-08-16 晚)

> 本文件是**当前唯一权威**的"系统长什么样 + 能声明什么"口径,取代同日更早的 novelty_statement 中与本档冲突的表述。
> 分界线:今天有四条预注册判据被自己证伪,凡被证伪的一律移入"不可声明"栏。

## 一、系统长什么样

### 写入侧(每个用户一次性,离线)

整库会话 → 一次批量调用(haiku)→ 六字段卡片。

每张卡:`值 / 陈述日期 / 逐字锚点 / 替换边 / 属主 / 槽位类`,外加 `slot_cardinality`(single/set,**已抽取但读取侧从不消费**,08-16 讲解时发现)。

硬约束一条:**`source_span` 必须是会话原文的逐字连续子串**,可用一行代码校验。

- 成本:**≈29k token/库 ≈ 6 美分**,一次性、离线、可批处理五折。
- 质量:归档那份卡片库(端到端成绩实际使用的那份)对源链**精确匹配 76.88%**(153/199);**建卡契约的期望质量 70.0%,95% CI [52.1%, 87.9%]**(n=3 重建,±20pp 方差实测)。**两个数字用途不同,不可混用。**(08-17 补注:该 ±20pp 是在未固定采样温度下测得;固定 temperature=0 复测后标准差 7.21→3.85pp,降 46.5%,**未达预注册"减半"阈值(≤3.6pp)**——即温度可解释一部分但非多数方差,区间本身**不改**,但其成因应表述为"主要仍是契约/抽取本身的固有不确定性,叠加一部分未控制的采样温度",而非纯采样噪声。详见 results/card_temperature_diagnosis_20260816.md)

### 存储:每用户一张微型时态事实表

卡片库是 JSON 里的记录数组。按 `(属主, 槽位类)` 分组后成为若干条**状态链**。

样本库 wikiP108011 的实况:**44 张卡 → 16 条链**;employer 链深 3(Manchester → Shell → Indian Institute);**23/44 = 52% 的卡片落在七类闭集之外**(`other:hobby` / `other:plants` / `other:healthcare` …)。

### 读取侧(每题独立,无跨查询状态)

```
问题
 ↓ ① 聚焦调用(小模型,~0.3k token)→ (槽位, 时序范围, 预设值)
 ↓ ② 路由:按 (问题时序性 × 该槽位键控深度 × 整库形态) 四选一
 ↓ ③ 编译:小模型 → 11 算子的严格 JSON 计划     ← LLM 在读取侧的唯一产出
 ↓ ④ 执行:纯 Python 在事实表上算 → 证据包 + 结论行   ← 零 token
 ↓ ⑤ 读者:把结论说成人话,强制逐条带日期引用
答案
```

**四臂实测分派(全体 5511 题)**:`prompt 2729 / wt 1949 / direct 440 / rt 393`。

**关键设计**:**无任何跨查询状态**——没有用户画像、没有"当前话题"。上一题问职业、下一题问饮食,路由各自独立判断。代价是**质量随话题在闭集内外跳变**(闭集内全功能,闭集外键控深度为 0/None → 降级到 prompt/direct)。

### 一条真实链路(归档产物,可复现)

问题:`(Today is 1984-07-01.) Which employer did I hold the longest?`

计划:`{"op":"longest","slot":"employer"}`

证据包(读者看到的全部内容):
```
[1970] employer: University of Manchester — "University of Manchester"
[1976] employer: Shell — "I've just started at Shell as of this morning"
[1984] employer: Indian Institute of Petroleum — "I've officially joined..."
```
结论行(**代码算的**):`Held longest (closed intervals only): Shell (2922 days).`

成本:**1824 in / 107 out ≈ 2k token,6.2 秒**。

### 现在的成绩

| 卷 | 直读 | QVF |
|---|---|---|
| 目标域 1664 题 | 61.3% | **88.8%** |
| 全体 15 卷 5511 题 | 60.3% | **70.2%** |
| S5 复杂查询 418 题(修 bug 后定稿) | 48.33% | **83.73%** |

答题边际成本:WikiState 域 **~2.1k token ≈ $0.0027/题**。

## 二、可声明的创新(六条,每条都经受住了今天的检验)

### 1. 问题形式化:有效性是二元函数
`valid : S × Q → {0,1}`——一条记忆过没过时,不是它自身的属性,而是 (记忆, 问题) 这一对的函数。
**隔离测量**:查询盲的"永远取最新"策略 32.0% vs 我们 86.5%,**+54.5pp**(措辞:量化"最新值优先"在时序题型上的**覆盖代价**,不说"击败它"——该策略作者自陈不处理历史查询)。

### 2. 读取侧的查询编译 → 代码执行 ★ 最硬的一条
版本选择与历史聚合由**代码**完成,不是答题模型。
**实测**:S5 定稿 418 题上 **48.33% → 83.73%,Δ=+35.4pp,簇稳健 p=4.14e-17**(84 胜 8 负 13 平,CI[+28.5, +42.1])。
**三个外部独立证据**:TimelineQA 检索式 QA 在聚合题上 85.1%→4.3%;Graph-Native Bitemporal Store 自证跨会话计数 30% R@10 并明言"检索无法回答";QO-Bench 检索交集 6.0% 而抽取到 SQL 平稳 ≈51%。
**最具说服力的单例**:直读检索到全部 3 个雇主、日期一个不错,然后回答"变了 3 次"(正确答案 2)。**证据满分,算术失败**——这类错误提示词修不了。

### 3. 六原语最小完备基(只主张表达力)
`P = {SELECT, TAGSET, WINDOW, PICK, ASOF, AGG}`,|P|=6,11 算子全部可表为深度 ≤3 的宏;跨槽位 join 被 ASOF 的表达式日期参数吸收。
**机器可检**:宏执行 vs 平面执行**逐字节等价 347/347**;编译良构率 67/67=100%;平面臂**结构性不可表达率 77.6%**。

### 4. 带证书的成本最优路由 + 结构性下界
`â(x) = argmax_a [ p̂_a(x) − λ·c_a ]`,λ 由 Learn-then-Test 校准。
**实测**:+1.94pp 且省 51.6% token;**去掉数据集身份特征后不降反升**(+2.23pp / −50.3%)。
**独有的负结果**:主口径证书**结构性不可达**——ε 曲线渐近 **9.27% > 目标 5%**,不存在有限校准集使其可发;oracle-gap 8.96pp 中 **97.4% 是排序误差**,重校准只能修 0.24pp。**这是"预测器离最优还差多远"的定量测量,文献中无人报告。**

### 5. 双时态索引的不变量与复杂度(只主张 2/11 算子)
四条完整性不变量在 **12,500 次随机插入零失败**;`chain_depth` **O(1) 查表**、`asof` **O(log 链长)** —— n=10⁵ 时 p50 分别 9.5ms / 8.8ms,而 O(n²) 参照外推需 **48 分钟**。
**诚实边界**:其余 9 个"证据枚举类"算子必须把支持链逐条吐成文本,**天然 O(链长),任何正确实现都绕不开**。

### 6. 预注册的自我证伪审计协议
代码级耦合审计(126 项手写制品三分类)+ 盲写改写鲁棒性(1107 条,零模板膨胀)+ 零改动新域测试(判据先于跑数写死)+ 修复重立。
**它在 08-16 一天内抓到的**:S5 的 `role` 正则 bug(致整个任职域被剔出样本框、成绩虚高)、论文骨架用旧系统版本数字支撑当前主张的完整性缺陷、Mem0 330k 引用查无出处、建卡 ±20pp 方差、四起"静默失败伪装成结果"。
**核实过的 30 篇同赛道文献中,没有第二家发布过自家代码的耦合清单,也没有第二家做过判据先行的零改动跨域测试。**

## 三、不可声明(今天被自己证伪的)

| 不可说 | 实测 |
|---|---|
| 发散查询("三杯鸡→高糖")可用 | P2 主判据被否定:格闭包召回 **4.5%** vs 门槛 60%,且与零结构的纯嵌入臂逐位相同 |
| 代数臂更准 | S8 未见组合 **49.3% < 平面臂 52.2%**,猜想被否定(根因是渲染器缺陷,非表达力) |
| 键控机制可泛化 | 已按预注册**撤回**,降为"闭集内成立";新域主判据至今不成立 |
| 乱序鲁棒 | seq==shuf 同答率 **77.8% < 95%** 门槛,判据触发 |
| 全部算子亚线性 | 只有 2/11 达到;其余天然 O(链长) |
| 写入侧质量 = 某个具体数 | 单点表述被自己证伪,须用区间 **70.0% [52.1, 87.9]** |

**并存的诚实边界**:载体全合成(从未见过真人对话)、单用户假设、库规模只有几十个会话、非中英文会漏检。

## 四、一句话与三句话

**一句话**:
> 我们把"记忆过没过时"从记忆的属性改写成 (记忆, 问题) 的函数,并给出第一个**由代码而非答题模型完成版本选择与历史聚合**的会话记忆系统——单这一个机制在同题配对上值 +35.4 分(簇稳健 p=4.14e-17)。

**三句话(答辩用)**:
> 一、读取侧:现有记忆系统到"把证据交给模型"就停了,我们把问题编译成可执行计划,版本选择、计数、拼链全由代码算——直读检索到全部三个雇主还是会答"变了 3 次"(正确是 2),这类错误提示词修不了。
> 二、两个可陈述的数学对象:11 算子的 6 原语最小完备基(逐字节等价 347/347 机器可检)、带 (ε,δ) 证书的成本最优路由(+2.2 分省 50% token,并证明证书的界是结构性下界)。
> 三、方法学:我们把"系统是不是被基准特调"做成了可执行的预注册审计——它今天抓到了自家一个让成绩虚高 6 分的 bug,我们改低了数字,而机制主张反而从 +31.8 升到 +35.4。
