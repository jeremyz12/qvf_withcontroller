## 〇、一分钟版本

**QVF 是什么**:长期对话记忆系统。写入侧把整库对话抽成六字段卡片(值/陈述日期/逐字锚点/替换边/属主/槽位类),按 `(属主, 槽位类)` 分组成状态链;读取侧每题走 聚焦 → 路由(四臂)→ 编译成 11 算子闭集 JSON 计划 → **纯 Python 执行** → 读者渲染。核心命题 `valid : S × Q → {0,1}`。

**目标**:ACL/NAACL 2027,距投稿 2–3 个月。

**当前诚实定位**:**合格的诊断/测量论文,不是方法创新论文**。三条候选技术创新已零成本全部证否,查新判 **0 条为新**(2 条已被 PODS 2007 与 Findings ACL 2025 占)。

**唯一抢不走的位置**:QVF 是唯一同时满足"**库自建(所以会错)**"和"**执行确定性(所以可单独测)**"的系统,因此是唯一能把端到端失败分解成"库的锅"还是"执行的锅"的**测量仪器**。首个读数:c₁ = 99.6% / c₂ = 46.2%。

## 四、为什么"现在表现不好了"——真答案

**不是 QVF 变差了,是四个原因叠在一起,只有一个是真的掉了。**

### 4.1 对照物一直在变强(最大原因)

| 时间 | 报的数 | 对照物 |
|---|---|---|
| 两周前 | 目标域 61.3 → 88.8(+27.5pp) | haiku + top-10 稠密直读 |
| 上周 | 全体 60.3 → 70.2(+9.9pp) | 同上,15 卷 5511 题 |
| 现在 | 结构化机制净 **+4.21pp** | **提示词臂**(65.94% @1,275 tok) |

三个数都真算出来过。变的是分母(5511 实为 **5061** unique qid)和对手(把提示词臂能拿的从总增益里扣掉)。

### 4.2 ⭐ 基线自己在涨,而且涨得比 QVF 快(这条是新发现,最该记住)

STALE 上按 `stale_type` 分层,同题对照:

| | 08-03 | 08-18 | 变化 |
|---|---|---|---|
| **直读基线(T1)** | 30.9% | **50.50%** | **+19.6pp** |
| **QVF(T1)** | 39.4% | **53.00%** | +13.6pp |
| **差距** | **+8.5pp** | **+2.50pp** | **缩小 6pp** |

**两边都在涨,但基线涨得更快。**基线的提升来自:嵌入后端换 OpenAI、读者模型升级、检索配置改进——**全是"免费"的外部进步,而 QVF 的提升要靠自己造。**

**这是这个项目最根本的战略处境:你在追一个自己也在跑的靶子,而靶子的加速度不比你小。**

### 4.3 T2 从一开始就是死的

STALE T2(隐晦更新):**+0.17pp**(31.67% vs 31.50%)。而 08-03 的日志原话就写着"隐晦更新对便宜抽取器根本超纲"。**这一半从来没活过。**

### 4.4 只有一处是真的掉了

`_FAMILY_TERMS["position"]` 的裸词 `role` bug:S5 **89.81% → 83.73%(−6.08pp)**。**而同一次修复里机制差从 +31.8 升到 +35.4。**

## 五、接下来应该怎么修(按优先级)

### 5.1 立刻做:把已改的四条修复上考场(成本 ≈$5,零新代码)

`QVF_DATE_STRICT` / `QVF_SLOT_STRICT` / `QVF_CARD_VERIFY_SPAN=3` **全部只验证过,没上过任何考场**。

**预注册判据(跑数前写死,不得挪动)**:
- 旗标关时逐字节等价必须 **N/N**
- 整体准确率允许下降,但若 `QVF_SLOT_STRICT` 导致下降 >3pp,须同时报告"链深信号修正前后的分布",并把下降归因为"此前键控深度被误并虚高 29%"
- **S8 持出集只准用一次**

**已测得的预期**:`QVF_SLOT_STRICT` 会让链数 +42.8%、平均链深 1.97→1.40(−29.0%),**更多题会降级到 prompt/direct 臂**。这个下降是**修正而非退步**。

### 5.2 高杠杆:链成员资格判定(<$4,2–3 天)

**72% 的错答来自"伪状态卡混入链"**,而那些卡逐字锚点、`record_id`、关系边**全部满分**——所以任何溯源信号都看不见它。

正确的问题不是"这张卡可不可信",是:**这张卡到底有没有宣告目标槽位的一次状态转变?**

为什么这个落点靠谱:①是**错误分布指出来的**,不是设计出来的;②有干净评测(**链一致的 266 题上准确率 100%,零例外** → 链保真度是充分条件,预测它比预测答案更干净);③只在自建库上存在(库给定时成员资格是给定的)。

### 5.3 补最难堪的实验缺口(≈$1,一小时)

**提示词臂从没在 S5 那 418 题上跑过**(`prompt_rows_all.jsonl` 的 4,482 个 qid 与 S5 交集 **0**)。

所以"QVF 在算术题上赢"目前**只有跨卷比较,没有同题证据**。**在跑出这张表之前,不得对外说"我们在复杂聚合上优于提示词基线"。**

### 5.4 便宜且可能大幅省钱:rt 臂的去留

rt 臂(现场抽取,已被 wt 臂取代的旧架构)**只占生产流量 7.8%,却要 13k–23k token/题**(直读 567)。

**零成本可算**:把 rt 的题改派 wt 或 prompt,整体掉多少?若掉得少,直接摘掉 rt,**平均 token 从 ~2.7k 降到 ~1.6k**。

### 5.5 定位层面:承认它是仪器论文

**唯一没被占的位置**是"库自建 + 执行确定性"的组合,而 c₁/c₂ 是它的第一个读数。走这条路必须先补基准的四个洞(见 5.6),因为**仪器的可信度就是它的标定**。

配套:**跨预算的准确率曲线** + **成本口径声明**。这个领域连成本口径都没有(两篇 ACL 2026 主会对同一 baseline 的 token 报数差 **3 倍**;APEX-MEM 自己两表差 2.7 倍),而 QVF 有完整可对账的成本数据。

### 5.6 基准必须补的四个洞(走仪器路线的前提)

| 缺陷 | 现状 | 必须做 |
|---|---|---|
| `longest_tenure` gold | "当前这份干得最长"形态覆盖率 **0/103**;接回真实 end 后 **55/92 = 59.8% 的 gold 被推翻** | 重生成 + 重跑 103 题 |

| 算子层契约违反 | **16.7%(245/1,463)** | 修或如实报为仪器噪声底 |

### 5.7 不该再做的

- **加算子、加槽位、加基准**:六次扩展尝试全死,形状一致(都在要求写入侧产出更多更深更准的结构)
