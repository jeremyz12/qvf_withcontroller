## 一、一句话主张

> **长期对话记忆的失效不是一个现象,是三类。按问法分开定价后,只有两类是
> 模型能力与提示词都买不到的:"某时点的值"(+27.9pp)与"全部值的聚合"
> (+59.4pp);而"当前值"与"过期预设"两类,一段指令即可,结构化机制
> 在那里是负收益(−5.1pp / −12.0pp)。**

形式化仍用原命题 `valid : S × Q → {0,1}`——一条记忆过没过期是 (记忆, 问题)
这一对的函数。**变的是:三类问法里只有两类是硬的。**

## 四、机制层:为什么是结构性的

| 读数 | 值 | 含义 |
|---|---|---|
| c₁ 链全对时单算子判对 | 99.6% [97.9, 99.9] n=266 ⚠️ | 库对了,单跳几乎必对 |
| c₂ 两链全对时组合题判对 | 46.2% [23.2, 70.9] **n=13** ⚠️ | **n 极小,报时必须同页写 n=13,不得报点估计** |
| 六原语符号验证 | **874 次逐字节比较,11/11 算子零不等价** ⚠️ | 执行层是确定性纯函数 |
| 算子层契约违反率 | 16.7%(245/1,463)⚠️ | 仪器自身的噪声底 |

**机制解释**:dim5 的答案不在任何单条记忆里,而在**多条记忆的有序关系**里。
检索返回的是记忆集合,提示词改变的是读者的态度——两者都不产生"顺序"这个结构。
只有把状态抽成带日期的链、再由代码遍历,才能得到它。

## 五、必须同页写的不利证据(它们让主张可信)

**1. 结构化机制在两类问法上是负收益** ✅
dim1 −5.1pp、dim3 −12.0pp。**这不是噪声,是边界。**

**2. 成本**(同 3,602 行三臂交集)✅
| | acc | tok | 延迟 |
|---|---|---|---|
| 直读 | 64.0% | 1,401 | 3.7s |
| 提示词 | 69.3% | 1,158 | 3.2s |
| QVF 整合路由 | 78.1% | 3,800 | 6.9s |

相对直读 **2.71× token / 1.88× 延迟**;相对提示词 **3.28× / 2.12×**。

**3. 路由不智能,且比"只知道卷"还差** ✅(本轮新测,n=1,964)
| 只知道什么 | in-sample 上界 |
|---|---|
| 最好的常数臂 | 81.67% |
| 只知道**卷** | 85.29%(+3.62pp) |
| 只知道**题型** | 84.27%(+2.60pp) |
| 卷 × 题型 | 86.86%(+5.19pp) |
| **QVF 出厂路由(实际部署)** | **82.94%** |
| 逐题 oracle | 90.33% |

**题型比卷少解释 1.02pp;出厂路由比两个单因素上界都低。**
→ **论文不得声称"按问题智能选择策略"。** 主张必须建在**能力边界的定价**上,不建在路由上。

**4. 闭集外新域会崩,且比不用还差** ⚠️
P69 就读域:编译臂 **21.3%** vs 直读 **76–96%**;`compile_ok 168/168=100%`(编译器没问题),
别名命中率 3.2%,空证据率 70.7%,**fail-open 让读者在空证据上继续猜**。
开放槽位规范化修复后 **21.3% → 60.0%(+38.7pp)**,旧域回归反升 +1.91pp;
但 fail-closed 仅 1/3 题型达标,"臂答必不劣于直读"**不成立**。

**5. `slot_cardinality` 中 set 占 36–39%,系统全部按替换链处理** ✅
现有基准只有 **1.5%** 的题触及该缺陷 → **基准测不出它**。

## 八、这个主张为什么比旧的强

1. **每一格都是同题配对**,不是跨卷比较
2. **主动包含对自己不利的两格**(−5.1pp / −12.0pp),审稿人拆不出新东西
3. **可证伪**:指出一个"dim5 类问题上提示词也能赢"的场景即可推翻
4. **把负结果变成论据**:边界越清楚,定价越有价值
5. **不依赖路由**——而路由恰是本项目最弱的一环

**最强的一句话**:换模型买不到(四档全零),加提示词买不到(+1.0pp),
只有把状态抽成带日期的链再由代码遍历买得到(**+59.4pp**)。
