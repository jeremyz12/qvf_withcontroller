# QVF 去耦合路线图(2026-08-15)

> 回答:"怎么避免为考场特调"。原则一句话:**凡是手写的具体内容(词条、示例、阈值、闭集),要么升级成模型/校准的输出,要么降级成缓存/文档——不许再承担机制职责。**
> 依据:耦合审计 126 项定性(QVF_coupling_audit_20260815.md);57 项 benchmark_specific 全部可归入以下五类处置。

## 一、五条去耦合原则(逐项对应审计发现)

| # | 原则 | 替换什么 | 替换成什么 |
|---|---|---|---|
| 1 | **词表→模型** | SLOT_ALIASES 58 词条、_EVENT_ARITH_RE 七短语正则、_FP_RE 人称表 | 聚焦调用(已存在的 LLM 分类步)加输出字段:规范槽位名、事件算术意图、owner——同一次调用,零新增成本;词表降级为缓存加速层,未命中不再决定行为 |
| 2 | **闭集→开放+规范化** | slot_class 七类闭集(other:* 二等公民)、CLOSED_TAGS 十标签 | 槽位类=开放字符串,下游按字符串本身分组(other:xxx 与具名类同权);标签走 P2 开放本体归纳(嵌入聚类+调和不变量) |
| 3 | **few-shot→规范文档** | COMPILE_PROMPT 六个与出题模板同构的示例(train-on-test 根源) | 编译提示词改为**算子语义规范**(formalization 草稿 §4 的指称语义表已是现成文本)+ 反例说明;若保留示例,必须取自一个永不进评测的持出域 |
| 4 | **口径单一来源+边界受检** | 出题器与执行器双侧手工同步的计数/最长/边界约定;≤ 边界被出题器剔除 | 边界约定作为执行器的指称语义**发表在论文里**(公开受审);出题器停止剔除边界情形——边界题进测试集,答错就答错,那是测量 |
| 5 | **阈值→校准、清单→数据** | depth 2/3、GATE_DEPTH=3、score 权重、BENCHES 硬编码、按基准名裁题 | P3 已示范:阈值=带 (ε,δ) 证书的校准输出;基准清单与 dev/test 切分改数据层 manifest/split 字段 |

## 二、你的提议:"把 QVF 训练成一个额外的模型"——这是去耦合的终点站

审计后重估,这个方向的价值**上调**了,因为它同时解决特调问题和 novelty 问题:

**QVF-Compiler(第一个模型)**:在改写测试与新域测试产出的**多域多表面形式**数据上微调 3-4B(5080 本地 QLoRA),训练域与评测域严格分离。它一次性完成三件去耦合:①few-shot 提示词整个消失(没有示例就没有模板锚定);②开放槽位规范化折叠进模型输出(问题→计划+规范槽名,原则 1/2 一并解决);③编译鲁棒性从"提示词工程的偶然"变成"在多样性数据上训练的性质",可以拿改写集/新域做正式的泛化评测。
**QVF-Writer(第二个模型,后置)**:建卡蒸馏,逐字锚点契约做 reject sampling。
**终态叙事**:"QVF = 两个小开源模型 + 纯代码执行器",全本地、全可复现、零 API——这是一个完整的系统贡献形态,发布模型权重本身就是 novelty(检索到的 30 篇里没有任何一家发布过时序查询编译小模型)。

前置依赖(这就是为什么它排在测试之后):训练数据的多样性恰好来自改写测试(表面形式)与新域测试(域多样性)的产出——**先测量,后训练,测量集永不入训**。

## 三、"更专业的数学"排队表

| 项 | 数学对象 | 状态 |
|---|---|---|
| P3 学习路由 | conformal 风险证书 (ε,δ)、Pareto 前沿、oracle-gap | ✅ 已落地+消融 |
| P1 组合代数 | 最小完备基命题(构造性归约)、组合泛化 split | 排队第一 |
| P4 类型检查 | 计划对库签名的良构关系、单调接受护栏、三层错误归因 | 排队第二 |
| P5 双时态索引 | 四不变量保持(归纳证明)、O(log n) 界、乱序 splice 语义 | 排队第三 |
| 口径规范化 | 执行器指称语义作为发表的形式规范(去耦合原则 4 的数学面) | 随 P1 一并写 |

P1 与去耦合还有一层联动:原语文档化(约 6 个原语的形式语义)天然取代 few-shot——组合式编译提示词只含原语定义,连示例都不需要,原则 3 自动满足。

## 四、研究队列(持续推进序)

1. ✅→⏳ **改写测试**(在跑):量化模板膨胀量,判据 >8pp 须标注
2. **零成本代码卫生**:split 字段替代按名裁题(评测线);fail-closed 与 open-slot 分组做成新旗标(不动冻结默认)
3. **零改动新域测试**(<$30,预注册判据已入档):P69/P1303/P26 三域受控
4. **P1 组合代数**(<$5):完备基命题 + 未见组合泛化
5. **QVF-Compiler 蒸馏**(本地 GPU,$0 现金 + 重评小额):用 1/3 产出的多样性数据训练,评测在持出域
6. P4 → P5 → S7 独立评审、边界/乱序压力子集
7. 汇合点:论文 Methods 用 formalization 草稿,泛化章用 1/3/5 的三层证据链(改写鲁棒/新域零改动/训练化编译器)

原则重申:每一步新机制走新旗标,v4.2 冻结数字永不改动;所有测量先预注册判据再跑数;负结果照常入档。
